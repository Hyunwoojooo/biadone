A few things to know.

Who is the beta for?

The current private beta is for people using Codex on macOS. The live landing page has the current application information.

Does Blabee create the suggestions?

Codex creates the suggestions. Blabee displays them in a small macOS panel and sends your choice back to the original conversation.

What happens after I request access?

On the live site, selected testers receive installation instructions by email. This independent design demo only previews the form; it does not submit a beta request.
