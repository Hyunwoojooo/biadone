2026.10.23

시작하기
1. 압축을 풀고 폴더 전체를 같은 위치에 둡니다.
2. index.html을 브라우저에서 엽니다. 설치나 인터넷 연결 없이 볼 수 있습니다.
3. A/B/C 시안을 열어 전체 페이지와 실습 예제를 비교합니다.
4. 비교 페이지의 데스크톱/모바일 미리보기와 검토 메모 다운로드를 이용할 수 있습니다.

세 가지 방향
A — a-studio.html: 화이트 스튜디오. 제작 결과물과 신뢰를 먼저 보여줍니다.
B — b-lab.html: 다크 작업실. 실제로 제목을 바꾸는 실습을 먼저 경험합니다.
C — c-guide.html: 블루 코스 가이드. 세 가지 서비스 선택과 상세 안내를 중심으로 봅니다.

공통 구성
- 포인트 색상 #2340FF
- 홈페이지 제작 + 운영 실습의 대상·준비물·결과물·진행 범위
- 서비스 설명용 홈페이지/가이드 예시
- 제목 변경·초기화가 가능한 무료 실습 예제
- 실습 체크리스트 TXT 다운로드
- 김동민·주현우 원형 흑백 프로필
- 지원 범위, FAQ, 실제 접수가 없는 상담 화면 미리보기

사진
최근 제공한 Image 1은 주현우, Image 2는 김동민으로 적용했습니다.
PNG 원본은 변경하지 않고 CSS로 원형 프레임과 #2340FF 테두리를 표시합니다.

검토에서 정할 내용
- 어떤 첫인상으로 시작할지: 결과물 / 체험 / 과정 선택
- 실제 제공할 결과물과 직접 수정 가능한 항목
- 진행 기간, 비용, 질문 지원 기간·채널, 추가 작업 기준
현재 시안에 확정 가격·일정·무제한 지원·고객 후기나 성과 수치를 만들지 않았습니다.

동작 범위
상담 화면은 입력 내용을 이 화면에서만 요약하며 실제로 접수·발송·저장하지 않습니다.
다운로드는 브라우저에서 이 기기로 파일을 만듭니다. 서버나 외부 서비스로 전송하지 않습니다.
샘플 화면은 서비스 설명용 구성 예시이며 실제 고객 사례가 아닙니다.
assets 폴더를 함께 보관해야 사진과 글꼴이 정상적으로 표시됩니다.

디자인 자료
concepts 폴더는 built-in image_gen으로 생성한 초기 시각 방향과 PROMPTS.txt를 담습니다.
최종 검토 대상은 실제 HTML입니다. HTML에는 제공받은 실제 인물사진을 사용합니다.
초기 이미지의 가상 인물·모호한 지원 약속은 실제 사진과 안전한 범위 안내로 교체했습니다.
그 외 의도적 차이: 기존 서비스 예시 사진 사용, 시안 간 전환 링크, 동작하는 입력 UI.

검증
Browser/IAB는 사용할 수 없어 기존 Playwright + Chromium으로 확인했습니다.
file:// 주소와 오프라인 상태에서 1440/1024/390/320px를 확인했습니다.
사진 원형 비율·포인트 색상·제목 수정·초기화·파일 다운로드·상담 미리보기·FAQ·모바일 메뉴를 확인했습니다.
레이아웃, 문구, 타이포그래피, 컬러, 사진, 섹션 순서와 모바일 화면을 디자인 방향과 비교했습니다.
프로덕션 파일 60개의 변경 전/후 SHA-256을 비교해 동일함을 확인했습니다.
기존 웹사이트를 수정하거나 배포하는 파일이 아닌, 분리된 검토용 HTML 패키지입니다.
