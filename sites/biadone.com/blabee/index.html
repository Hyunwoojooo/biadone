FAQ

Before you get started

What Blabee does, what you need, and how it fits into your Codex workflow.

Does Blabee generate the suggestions?

No. Codex creates the suggestions. Blabee displays them in a small macOS panel and sends your selection back to Codex.

Will I lose my conversation context?

No. Your choice is sent as your next message in the original Codex conversation. You don’t need to start a new conversation or repeat your instructions.

When does Blabee show suggestions?

When Codex provides useful next steps for a connected conversation. Suggestions can follow coding work or an explanation; they don’t have to appear after every reply.

Does the beta support Claude Code?

The private beta currently supports Codex on macOS. Support for Claude Code and other agents is not confirmed.

Do I need another AI API key?

No. Blabee uses suggestions from your connected Codex conversation. It does not require a separate AI API key or run another AI model.
