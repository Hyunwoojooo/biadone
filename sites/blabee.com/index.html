FAQ

A few things worth knowing

Straight answers based on the current private beta.

Does Blabee create the next actions?

No. Codex creates the choices. Blabee surfaces them and sends your selection back to the original session.

Does it open a new Codex session?

No. Your selection is delivered as a new user turn in the original Codex session.

Does Blabee appear after every Codex response?

No. It appears only when Codex has useful next actions for the current response and the current session is correctly bound.

Does the beta support Claude Code?

The current private beta is Codex-first. Support for other agents is not confirmed yet.

Do I need another AI API key?

No. Blabee does not add a separate LLM API key or inference service.
