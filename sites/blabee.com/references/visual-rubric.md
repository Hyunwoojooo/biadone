# Landing Page Visual Rubric

Rate each category as `pass`, `needs work`, or `fail` during the browser polish pass. A failed category blocks visual sign-off.

| Category | Pass condition |
| --- | --- |
| Brand specificity | The page is recognizably Blabee without relying on generic AI motifs. |
| Hero comprehension | Product, audience, outcome, and primary action are clear within a few seconds. |
| Product prominence | The four-decision interface is more important than decoration or character art. |
| Content hierarchy | Each section advances one clear part of the narrative. |
| Typography | Scale, weight, line height, and wrapping are consistent at every target viewport. |
| Spacing | Gutters, section rhythm, and component spacing follow a small coherent system. |
| Image quality | Real approved assets render sharply with intentional crops and aspect ratios. |
| Responsive composition | Mobile, tablet, and desktop layouts recompose intentionally without overflow. |
| CTA clarity | One primary CTA remains visible, usable, and connected to a real conversion event. |
| Interaction quality | Hover, focus, selected, keyboard, and reduced-motion behavior are coherent. |
| Content truth | No fake social proof or unsupported product, privacy, or security claim is present. |
| Completeness | Header, required sections, product media, final CTA, metadata, and footer are complete. |

For every `needs work` or `fail`, record the viewport, observable defect, smallest defensible correction, and post-fix evidence.
