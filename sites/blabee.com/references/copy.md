# Blabee Copy and Claim Guide

Status: current private beta copy, dated 2026-08-29.

## Message

Blabee shows the ranked next actions that Codex prepared and sends the user's shortcut selection back to the original Codex session.

The page must make four benefits clear:

- The user does not return to the terminal for one decision.
- One shortcut replaces rereading a long response or writing a new prompt.
- The selection continues the existing Codex session rather than opening a new one.
- Blabee stays quiet until Codex has useful next actions and the session is correctly bound.

## Language

- English is the only published language.
- All headings, body copy, demo states, form labels, loading, error, success, title, metadata, and accessibility labels are English.

## Product truth

- Say that Codex creates the choices.
- Say that Blabee displays the choices and sends the selection.
- Limit current availability to a Codex-first macOS private beta.
- Describe the current ranked flow as two to four next actions, with the first action recommended.
- Do not present pause or rollback as fixed or enabled current slots.
- Keep Claude Code support explicitly unconfirmed.
- State that Blabee does not add a separate LLM API key or inference service.

## Prohibited claims

Do not present Blabee as independently generating recommendations or providing a separate LLM, decision layer, safety engine, long-term memory, Git rollback engine, or multi-agent manager.

Do not publish invented customer logos, testimonials, user counts, ratings, integration lists, security certifications, privacy guarantees, or performance metrics.

## Conversion truth

The page may invite a Mac private-beta application. It must not say the application was stored unless a real form endpoint confirms success.
