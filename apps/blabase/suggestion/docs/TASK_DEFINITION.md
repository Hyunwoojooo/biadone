# Priority Task Definition v0.1

## 추천 대상

Priority task는 사용자가 지금 직접 처리해야 하거나, 사용자와 AI가 함께 처리해야
하는 아직 끝나지 않은 일이다. 다음 중 하나 이상의 직접 근거가 있어야 한다.

- 사용자가 하겠다고 명시한 일
- 사용자가 직접 요청한 일 중 사용자 행동이 필요한 부분
- assistant가 제안하고 사용자가 명시적으로 수락한 다음 단계
- 사용자의 다른 일을 막고 있는 미해결 단계
- 사용자의 결정 또는 확인을 기다리는 열린 질문

## 추천 제외

- 완료, 취소 또는 대체된 일
- assistant만 제안하고 사용자가 수락하지 않은 일
- AI가 단독으로 처리해야 하는 일
- 예시, 인용문, 템플릿, 코드 또는 가상 상황에만 등장하는 일
- 정확한 사용자 evidence가 없는 추론
- 완료 여부나 담당자가 충돌하지만 시간 순서를 확정할 수 없는 일

## 우선순위 원칙

1. 검증된 명시적 마감
2. 다른 작업을 실제로 막는 선행 단계
3. 사용자의 명시적 약속 또는 요청
4. 여러 대화에서 안전하게 병합된 반복 신호
5. 짧은 시간 안에 바로 시작할 수 있는 정도

최근에 언급됐다는 사실만으로 최우선 task가 되지 않는다. 상위 두 후보의 점수
차이가 작고 명확한 마감 우위가 없으면 한 가지 clarification 질문을 반환한다.

## 추천 문구

`whyNow`는 검증된 우선순위 reason code로 코드가 작성한다. LLM이 생성한 긴급성
표현을 그대로 사용하지 않는다. `firstStep`에 evidence에 없는 날짜 또는 긴급
표현이 포함되면 결정적 안전 문구로 대체한다.
