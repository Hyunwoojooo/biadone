이 숫자를 어떻게 해석해야 하나요?

현재 코드가 기존 deterministic 계약을 깨지 않았다는 근거입니다. 실제 사용자 유용성, source adapter 정확도, production 분포, 외부 베타 준비를 증명하지 않습니다. Golden/holdout의 evidence class가 올라가야 release claim도 올라갑니다.

Known risks

지금 숨기면 안 되는 경계

  • Synthetic ≠ product quality. 현재 cross-source 평가는 mutable Dev Candidate이며 사람 검토 Golden과 locked holdout이 없습니다.
  • Memory/session persistence. 대화 분석 결과는 새 브라우저·기기·장기 보관·공유 URL을 지원하지 않습니다.
  • Source drift. ChatGPT 공유 payload는 바뀔 수 있고 현재 커밋된 HTML fixture는 한 개뿐입니다.
  • Local runtime boundary. scheduler/lease와 multi-process ownership은 production 수준으로 닫히지 않았습니다.
  • macOS distribution. full XCTest/XCUITest, Developer ID, hardened runtime, notarization이 남았습니다.
  • Privacy & retention. cross-source 집계와 평가에는 최소 수집·삭제·동의·lawful review 결정이 필요합니다.
  • Dirty launcher worktree. 현재 미커밋 Swift 변경은 완료 상태나 clean-provenance release 근거에 포함하지 않았습니다.
