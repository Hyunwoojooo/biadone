# 강화학습의 데이터·사업성 문제와 자동 적응 접근

## 한눈에 보기

- 강화학습 경험 데이터를 얻기 어려운 분야에서 시작해 환경 변화에 따른 재학습 비용과 사업성을 검토했다.
- 로봇 AI에서는 딥러닝·모방학습·강화학습과 전통 제어가 역할을 나누며, 정책 전체를 계속 재학습하는 방식만이 답은 아니라는 결론에 도달했다.
- 자동 적응 연구의 주요 계열은 정리됐지만 사용자가 적용할 로봇과 방법은 선택되지 않았다.

## 핵심 정리

- 강화학습의 데이터 부족은 라벨뿐 아니라 상태·행동·보상·다음 상태 궤적, 성공·실패 판정과 선호 피드백의 부족을 뜻한다.
- 실제 시행착오가 비싸고 환경이 비정상적이며 보상이 지연되는 문제에서는 end-to-end RL의 사업성이 약해질 수 있다.
- bandit, 보수적 offline RL, 일부 모듈 최적화, world model·MPC와 residual 보정처럼 학습의 역할을 제한하면 활용 가능성이 남는다.
- 로봇 인식·조작에는 딥러닝·모방학습이, 보행·전신 제어에는 deep RL이 상대적으로 강하며 실제 시스템은 전통 제어와 결합된다.
- 환경 변화 대응은 컨텍스트 추론, continual/online RL, 변화 감지·policy switching, system identification+MPC와 goal-conditioned policy로 나뉜다.

## 주제별 정리

### 1. 경험 데이터를 얻기 어려운 이유

사용자의 첫 질문은 로봇 동작 데이터나 주식처럼 웹 텍스트에 비해 양질의 데이터 또는 정답 행동을 얻기 어려운 분야가 어디인지였다. 강화학습의 데이터는 단순한 분류 라벨이 아니라 상태·행동·보상·다음 상태로 이어지는 궤적, 성공·실패 판정과 인간 선호 같은 피드백까지 포함한다는 설명이 먼저 제시됐다.

로봇·자율주행·드론의 물리 제어, 반도체·화학 공정·전력망 같은 산업 운영, 의료, 재난·장애 대응, 교육·상담, 금융·광고·사이버보안, 법률·규제와 물류·교통이 예로 들었다. 이 영역에서는 실제 탐색이 위험하거나 비싸고, 보상이 늦거나 희소하며, 하지 않은 행동의 결과라는 반사실을 관측할 수 없다. 환경이 계속 변하거나 중요한 사고 사례가 드물고 전문가 라벨도 비싸다는 문제가 겹친다.

시뮬레이션, offline RL, 모방·선호·자기지도학습과 world model이 데이터 부족 완화책으로 제안됐다. 그러나 각 방법이 안전한 탐색, 분포 이동과 보상 정의 문제를 자동으로 없애는 것은 아니며, 사용자가 특정 접근을 선택한 것도 아니다.

### 2. 재학습 비용과 사업성

사용자는 환경이 조금만 바뀔 때마다 강화학습을 다시 해야 한다면 유지·운영 비용 때문에 사업적 이점이 사라지는 것 아니냐고 물었다. Assistant는 경쟁적이고 비정상적인 환경, 실제 시행착오가 비싼 분야, 지연 보상과 부분 관측이 강한 문제에서는 교과서식 end-to-end RL의 사업성이 제한적일 수 있다고 답했다.

반면 행동이 미래 상태를 바꾸는 순차 의사결정이고, 보상을 측정할 수 있으며, 안전한 평가와 업데이트 체계를 만들 수 있는 좁은 문제에는 가치가 남는다고 구분했다. 짧은 의사결정에는 contextual bandit, 기존 제어·최적화 시스템의 일부 파라미터만 학습하는 방식, 보수적 offline RL, world model을 갱신하고 MPC로 재계획하는 방식, 환경 컨텍스트를 정책 입력으로 받는 방식이 예로 제안됐다.

주식 시장은 비정상성, 부분 관측, 거래비용, 반사실 부재와 시장 참여자에 의한 알파 소멸이 동시에 나타나 일반적인 RL로 안정적 초과수익을 내기 특히 어려운 사례로 설명됐다. 전체 투자 정책보다 리스크 관리나 주문 집행처럼 범위가 제한된 하위 문제에 적용하는 편이 더 현실적이라는 제안이다. 이는 특정 전략의 수익성이 입증됐다는 뜻은 아니다.

### 3. 로봇 AI의 실제 역할 분담

딥러닝과 강화학습은 양자택일이 아니라 모델 표현과 최적화 방식의 관계로 설명됐다. 카메라·라이다·촉각의 인식과 상태 추정에는 지도·자기지도 딥러닝이 중심이고, 팔·손 조작에는 시연 기반 모방학습·행동복제·확산정책·VLA가 강한 흐름으로 정리됐다. 보행·전신 제어는 시뮬레이션에서 대량 시행착오를 만들 수 있어 deep RL의 비중이 상대적으로 크다.

실제 시스템은 PID·임피던스 제어·MPC가 안정성과 제약을 담당하고 학습 모듈이 목표 궤적, 발 디딤, 참조값이나 residual 보정을 맡는 하이브리드 구성이 흔하다는 설명이다. 이 역할 분담은 환경이 변할 때 거대한 정책 전체를 다시 학습하는 대신 식별·계획·보정 모듈만 바꿀 수 있다는 사업성 논의와 연결됐다.

### 4. 자동 적응 연구 계열

첫 계열은 정책 가중치를 매번 다시 학습하지 않고 최근 관측·행동·보상에서 숨은 환경 컨텍스트를 추론해 정책 입력으로 쓰는 방식이다. Meta-RL, RL², MAML, PEARL, RMA, online system identification과 universal policy가 마찰·지형·적재량·마모 변화에 추론 단계에서 빠르게 대응하는 예로 소개됐다.

두 번째는 운영 중 가중치를 계속 갱신하는 continual·online RL이다. 새 환경을 배우면서 이전 능력을 잊는 catastrophic forgetting과 업데이트 도중의 안전이 핵심 난제이며, replay, 부분 파라미터 업데이트, 안전 제약과 drift 감지 뒤 제한 학습 같은 완화책이 연구된다고 설명됐다.

세 번째는 변화 시점을 감지한 뒤 최근 데이터 구간을 바꾸거나 여러 정책 중 적합한 것을 선택하는 change-point detection·policy switching이다. 로봇에 더 실무적인 조합으로는 동역학을 온라인 식별하고 MPC가 매 순간 재계획하며 RL은 튜닝·residual만 맡는 구조가 제안됐다. 목표나 보상 규칙이 바뀌는 경우에는 goal-conditioned policy, UVFA, successor features와 multi-objective RL로 전체 재학습을 줄일 수 있다는 설명도 포함됐다.

자동 적응 연구가 존재한다는 사실과 실제 운영 문제가 해결됐다는 주장은 구분해야 한다. 사용자가 염두에 둔 로봇 종류, 무엇이 얼마나 빨리 변하는지가 제시되지 않았기 때문에 어느 계열이 적합한지는 결정되지 않았다.

## 결론과 확정된 결정

- **정리된 결론:** 변화가 큰 실제 시스템에서는 전체 정책의 반복 재학습보다 전통 제어·모델 기반 계획과 제한된 학습 적응을 결합하는 방식이 현실적일 수 있다.
- **사용자 확정 결정:** 없음.
