검증일: 2026-10-24. 대상은 개인 Mac의 로컬 롱폼 에디터입니다. 별도 OpenAI API 호출·키 저장·전역 Codex 설정 변경·외부 배포 없이 검증했습니다.

## 실제 롱폼 출력

- 프로젝트: `project-d93fec82-85e7-4612-bf94-e465f3179f21`
- 작업: `a52aeefc-b0a3-4b86-b14e-1d29d9547b43`
- 출력: [5분 32초 검증 영상](../data/jobs/a52aeefc-b0a3-4b86-b14e-1d29d9547b43/output/video.mp4)
- 1920×1080 · 30fps · H.264/AAC · 332.866초 · **9,986프레임 전체 디코딩**
- faststart 통과. HTTP 전체 다운로드 14,224,489바이트와 원본 출력 SHA256 일치.
- 처음·중간·끝 6초 음성의 상관도 0.9988 이상, 지연 모두 0ms.
- Chrome에서 1·166·329초 구간으로 이동한 뒤 실제 재생과 readyState 4·미디어 오류 없음 확인.
- 원본 나레이션·기존 전사 파일의 SHA256 보존.
- 전체 출력·검증 709.691초. 이 시간은 현재 Mac·현재 프로젝트의 측정치입니다.

이 출력은 고정된 리비전 3의 자동 구성 초안입니다. 당시 문구 밀도 경고 8개를 명시적으로 승인했고 품질 오류는 0개였습니다. 이후 새 자동 구성은 단어 경계에서 원문을 발췌하고 `…`를 표시하도록 개선했습니다. 기존 프로젝트·출력을 바꾸지는 않았습니다.

## 화면·음성 일관성

제목, 인용, 비교, 단계, 캐릭터, 이미지, 영상의 7개 장면으로 6개 유형을 실제 출력했습니다. 각 장면의 시작·정착 프레임, 한글, 두 줄 자막, 안전 영역과 실제 미디어를 직접 검토했습니다. 테스트 장면을 각각 2초로 만든 데 따른 읽기 속도 경고 6개는 예상 범위로 승인했습니다.

삽입 영상에 넣은 880Hz 원음의 출력 잔차는 원본의 0.014%이며, 마지막 장면의 나레이션 상관도는 0.999835·지연 0ms였습니다. 영상 원음 중복 없이 주 나레이션이 이어집니다.

AAC 탐색 시 정상 파일을 잘못 판정할 수 있는 측정 아티팩트를 재현해 검사기를 수정했습니다. 현재는 리샘플 후 샘플 인덱스로 필요한 구간만 자르고, 메모리에 최대 6초 PCM만 보관합니다. 기존 14초·5분 32초 영상과 12.1초 소수 구간을 재검사해 상관도 0.9984 이상·지연 0ms를 확인했습니다. [정밀 음성 검사](validation/narration-precision.json)

미리보기와 MP4 비교는 같은 프로젝트의 0·42·59·60·222·342·402·419프레임을 사용했습니다. 브라우저의 소수 픽셀 좌표를 정렬하고 H.264 색차 압축 차이를 제외한 휘도 SSIM은 **0.9153–0.9752**입니다. 영상 소스의 타임코드도 같은 프레임이었습니다. 무손실 픽셀 동일성을 주장하지 않습니다.

## 브라우저·디자인 검증

Browser 플러그인이 제공되지 않아 설치된 Chrome을 사용하는 별도 headless Playwright로 검증했습니다. 사용자 브라우저 세션을 조작하지 않았습니다. 화면 크기는 **1536×1024, 1280×800, 390×844**입니다.

검증 경로: 프로젝트 열기 → 문구 수정·저장 → 새로고침 → 실행 취소·다시 실행·이력 복원 → 잠금·분할·병합 → 품질 오류와 수정 → 재생·탐색 → 동시 수정 충돌 → 파일 가져오기 → 실제 전사 → SRT 파일 가져오기·자막 직접 수정 → 이미지 연결 → 출력·다운로드 → 실행 중 취소·재시도 → 30분 타임라인.

입력 파일 선택 직후 UI가 FileList를 비우더라도 가져오기 작업이 사라지지 않도록 파일 목록을 즉시 복사합니다. 늦은 폴링 응답은 최신 초안을 덮어쓰지 않으며, 재적용할 장면이 사라졌을 때도 검증에 성공하기 전에는 초안을 버리지 않습니다. 다이얼로그의 이름·Escape·원래 버튼으로 포커스 복귀도 확인했습니다.

기준 디자인: [생성 컨셉](../assets/editor-concept.png), [디자인 명세](DESIGN.md). 기본 Image Gen 도구로 만든 컨셉을 기준으로 실제 브라우저 화면을 `view_image`에서 직접 대조했습니다.

## 현재 범위와 사용 전제

- 자동 검수는 레이아웃·자산·시간·미디어 무결성 기준입니다. 대본의 사실성·발음·설명과 화면의 의미·연출의 완성도는 사람이 확인합니다.
- 실제 전체 렌더는 5분 32초까지 확인했습니다. 30분은 상태 구성과 탐색을 확인했고 전체 30분 렌더·장시간 성능은 별도 측정하지 않았습니다.
- 캐릭터는 일정한 2D 자산과 간단한 표정·파형 기반 입 움직임입니다. 생성형 인물·음소 립싱크를 제공한다고 표시하지 않습니다.
- JSON 내보내기는 편집 정보입니다. 백업은 미디어가 들어 있는 `data/` 폴더 전체를 보관해야 합니다.
- MCP 서버는 실제 프로토콜로 검증됐고 연결 명령을 제공합니다. 사용자의 Codex 설정에 자동 등록하지 않았습니다.
- `.command`는 실행 권한·구문을 확인했고 최종 서버는 `npm start`로 실행했습니다. Finder 더블클릭의 사람 수용 검사는 별도입니다.

추가 사용자 승인 없이 필요한 로컬 구현·검증은 완료했습니다. 커밋·배포는 하지 않았습니다.
