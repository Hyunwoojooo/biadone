# 장면 카드와 Codex 생성

상태: 2026-10-26 구현·검증 완료. 장면 구성 화면은 챕터·장면 추가, 연결된 나레이션, 화면 유형, 장면별 필수 요구사항을 중심으로 구성한다.

## 제작 흐름

1. 소스 준비에서 녹음·자료를 가져오고 자막을 만든다. 새 전사는 기존 장면 구성을 유지한다.
2. 장면 구성에서 챕터를 추가하고 이름을 정한다.
3. 장면 추가에서 처음·마지막 문장을 선택한다. 장면 길이는 해당 음성 구간으로 계산한다.
4. 카드에서 화면 유형과 필수 요구사항을 지정하고 장면 생성·재생성 또는 전체 생성을 누른다.
5. 같은 화면 아래에서 결과를 재생하고 적용한다. 생성 결과 탭에서도 보관한 초안을 볼 수 있다.
6. 편집에서 문구·자료·스타일을 다듬고 검수 후 출력한다.

큰 전역 분할·유형 전체 선택·기본 움직임·공통 요청 폼은 표시하지 않는다. 기존 API와 프로젝트의 설정 필드는 호환을 위해 유지한다.

## 문장 선택과 시간축

`addScene`은 `chapterId`, `firstCaptionId`, `lastCaptionId`와 선택적인 `preferredKind`, `requirements`, `idSeed`를 받는다. 처음 문장은 프로젝트 시작, 마지막 문장은 프로젝트 끝까지 확장하고 중간은 인접 자막 사이 무음의 중간 프레임을 사용한다.

선택 구간을 새 장면 하나로 묶고 바깥 장면은 보존한다. 경계 장면을 나눌 때도 기존 문구·요구사항·미디어를 유지하고, 오른쪽 영상 조각의 원본 재생 위치를 보정한다. 전체 프레임에는 빈틈과 겹침이 없어야 한다. 녹음·단어·자막의 순서와 시간은 이동하지 않는다.

겹친 잠금 장면, 없는·역순 문장, 선택 경계가 모호한 중복 자막은 원자적으로 거부한다. 새 장면은 한 번의 수정 이력이며 실행 취소·다시 실행·재열기가 가능하다. 명령에 고정한 seed로 클라이언트와 서버의 새 ID를 일치시켜 빠른 후속 편집을 지원한다.

중간에 챕터를 끼워 A→B→A가 되어도 카드·왼쪽 목록·타임라인은 재생 순서를 표시한다. 빈 챕터는 구성 화면 마지막에 표시한다.

## 사용자 요구와 AI 결과

- `Scene.requirements`는 최대 4,000자의 사용자 원문이며 줄바꿈을 포함해 보존한다. 입력 요소와 서버 스키마 모두 한도를 적용한다.
- AI가 만든 `notes`와 분리하며 생성 출력 스키마에는 요구사항 수정 필드가 없다. 생성·재생성·적용 후에도 사용자 지시는 남는다.
- 직접 지정한 화면 유형은 기존 전역 자동 선택 목록보다 우선한다. 자동 선택에는 저장된 기본 목록을 사용한다.
- Codex에는 `userRequirements`와 사용 가능한 유형·자료, 나레이션 구간을 전달한다. 일반 연출·이전 생성 메모보다 장면별 요구를 우선하되 실제 자료·내용 근거·시간·출력 스키마의 제한을 유지한다. 구현할 수 없는 요구는 결과 메모에서 알리도록 지시한다.
- 별도 OpenAI API 키 없이 기존 Codex CLI 로그인을 사용한다. 생성 요청 시 대본·요구사항·자료 이름과 메타데이터가 전달된다. 원본 미디어 파일 전송이나 새 이미지·영상 생성은 포함하지 않는다.

## 생성과 검토

생성은 현재 리비전과 정확한 장면 범위를 스냅샷으로 고정한다. 기본 CLI는 10장면씩 순차 처리하며 자동 provider 재시도 없이 취소·시간·결과 크기를 제한한다. 모든 범위의 검증이 끝나야 적용 가능한 초안이 된다.

초안은 프로젝트에 자동 적용하지 않는다. 시간축·잠금·존재하는 자료·영상 길이·유형별 항목 수·레이아웃을 검사하고 보관한 스냅샷으로 미리보기한다. 적용은 원본과 현재 리비전이 일치할 때만 가능하다. 편집된 상태를 덮지 않고 결과를 보관한다. 적용된 초안은 별도 표시한다.

완료 상태는 파일 저장 후 공개한다. 지연된 진행 알림은 완료 상태를 덮어쓰지 않으며 정상 종료는 작업과 저장을 drain한다. 전역 Codex 설정이나 인증을 복사·수정하지 않고 별도 sqlite_home도 지정하지 않는다. read-only/ephemeral 옵션이 CLI 자체의 상태 기록·인증 갱신까지 없애거나 모든 관리 기능을 완전히 격리한다는 의미는 아니다.
