# Biadone Studio

나레이션을 먼저 준비하고 장면 단위로 편집하는 개인용 롱폼 영상 에디터입니다. React 미리보기와 Remotion 출력이 같은 장면을 사용하며, 프로젝트·녹음·작업 기록은 컴퓨터 안에 저장합니다. OpenAI API 키가 필요하지 않습니다. 장면 생성 버튼은 기존 Codex CLI 로그인으로 나레이션에 맞는 화면 초안을 만듭니다. Codex에서 에디터를 직접 조작하는 MCP 연결도 지원합니다.

## 실행

Mac에서 `Biadone Studio.command`를 더블클릭하거나 다음을 실행합니다.

```bash
cd /Users/joo/BiaDone/apps/Edu/editor
npm install
npm run build
npm start
```

주소: **http://127.0.0.1:4317**. 종료는 실행한 터미널에서 Control-C입니다. 개발 모드는 `npm run dev`입니다. 기본 출력은 **1920×1080 · 30fps · MP4(H.264/AAC)**이며, 720p 검토 출력과 선택 장면 출력도 지원합니다.

필수 환경: Node.js 22.12 이상, Google Chrome/Chromium, FFmpeg. Chrome은 렌더링에 사용하고 외부 사이트에 미디어를 보내지 않습니다. Remotion 라이선스는 개인·소규모 조직과 그 외 조직에 적용되는 조건이 다르므로 [공식 조건](https://www.remotion.dev/docs/license/faq)을 확인하세요.

## 한 편 만드는 순서

1. 상단 로고 → **프로젝트**에서 새 영상을 만듭니다. 처음 열리는 예제는 화면 구성을 살펴보기 위한 예제이며 나레이션이 없습니다.
2. **소스 준비**에서 녹음과 이미지·영상을 가져옵니다. 첫 오디오가 나레이션으로 연결됩니다. 여러 녹음 중 하나를 선택할 수도 있습니다.
3. **녹음에서 자막 만들기**를 실행하거나 SRT·VTT·전사 JSON을 가져옵니다. 로컬 전사 결과는 발화 시간과 단어를 보관합니다. 분석 중 편집한 경우 새 결과가 기존 작업을 덮어쓰지 않고 작업 결과 파일로 보관됩니다.
4. **장면 구성**에서 **챕터 추가**로 흐름을 나누고 **장면 추가**에서 처음·마지막 문장을 선택합니다. 선택한 녹음 구간을 하나의 장면으로 만들며 길이는 자동 계산합니다. 각 카드에서 화면 유형과 **필수 요구사항**을 지정합니다. 카드·왼쪽 목록·타임라인은 녹음 순서를 유지합니다.
5. 카드의 **장면 생성·재생성** 또는 상단 **전체 생성**을 누릅니다. 결과는 같은 화면 아래에서 재생하고 **초안 적용하고 편집**으로 적용합니다. **생성 결과** 단계에서도 보관된 초안을 볼 수 있습니다. 필수 요구사항은 생성·재생성·적용 후에도 원문을 유지합니다. 생성 중 편집하면 현재 내용을 덮어쓰지 않고 초안을 보관합니다.
6. **편집**에서 장면을 선택하고 핵심 문구·비교·단계·체크리스트·수치 강조·흐름도·이미지/영상·캐릭터·인용 템플릿을 적용합니다. 문구 입력 후 다른 곳을 누르면 자동 저장됩니다. 항목 제목과 설명, 강조 색, 자막, 움직임을 조절할 수 있습니다.
7. 자막의 문구와 시작·종료 초를 수정하고 재생으로 확인합니다. 장면을 나누거나 합쳐도 나레이션 시간은 이동하지 않습니다. 영상 클립을 나누면 원본 재생 위치도 유지됩니다.
8. 확정한 장면은 **장면 잠금**으로 보호합니다. 상단 실행 취소·다시 실행·수정 이력에서 이전 편집으로 돌아갈 수 있습니다.
9. **검수 · 출력**에서 오류를 해결합니다. 확인 권장 항목은 검토 후 출력 창에서 확인 표시를 합니다. 실제 출력은 고정된 편집 버전으로 진행되며 작업 기록에서 진행률·취소·재시도·다운로드를 제공합니다.

키보드: Space 재생/정지, 좌우 방향키 1초 이동, Command-S 저장, 입력창 밖에서 Command-Z/Shift-Command-Z 실행 취소/다시 실행.

## 품질 기준

- 자막과 장면은 별도 프레임 시간축으로 관리합니다. 장면 사이의 누락·겹침, 잘못된 범위를 검사합니다.
- 공통 한글 폰트(Noto Sans KR)를 로컬에 포함하고, 제목·본문·카드·자막의 안전 영역과 글자 배치를 렌더러와 같은 계산으로 검사합니다.
- 미디어 누락·영상 길이 초과·자막 겹침·텍스트 넘침·낮은 강조색 대비 같은 오류는 출력을 막습니다.
- 출력 후 해상도·fps·길이·프레임 수·codec·faststart를 검사하고 파일 전체를 디코딩합니다. 나레이션이 있으면 처음·중간·끝 구간의 실제 오디오 상관관계와 지연을 검사합니다.
- 발음·정보의 정확성, 연출의 자연스러움과 메시지 전달은 사람이 재생하며 확인해야 합니다. 자동 검수 통과가 콘텐츠의 완성도를 대신하지 않습니다.

캐릭터는 고정된 2D 도형과 눈 깜빡임·호흡·음성 파형에 따른 입 움직임입니다. 생성형 인물 영상이나 정교한 음소 립싱크는 포함하지 않습니다. 영상의 움직임은 프레임을 기준으로 재현합니다.

## Codex로 장면 생성

설치된 Codex CLI와 기존 로그인 상태를 사용합니다. **장면 카드의 생성 버튼과 전체 생성은 MCP 등록 없이 동작**하며, 별도 OpenAI API 키를 요구하지 않습니다. 로그인이 없으면 터미널에서 `codex login`을 실행한 뒤 ‘다시 확인’을 누르세요. 실제 사용량과 이용 가능 여부는 로그인한 계정의 Codex 조건을 따릅니다.

이 기능은 완전한 오프라인 AI가 아닙니다. 생성을 요청하면 선택 구간의 나레이션 대본, 장면 설정과 자료 이름·종류·길이 정보가 Codex에 전달됩니다. 원본 음성·이미지·영상 파일 자체를 전송하는 기능은 추가하지 않았습니다. 내장 모션그래픽과 이미 가져온 자료로 화면을 만들며, 새 이미지·영상 또는 정교한 립싱크를 생성하지 않습니다.

Codex는 구조화된 데이터만 반환하고 에디터가 유형·자료·시간·잠금·레이아웃을 검증합니다. 생성 초안은 작업 폴더에 보관되며 적용 전 미리보기할 수 있습니다. 변경된 리비전을 덮어쓰지 않고, 취소·실패·재시도도 작업 기록으로 남깁니다. 긴 영상은 작은 묶음으로 순차 처리합니다.

## Codex에서 에디터 조작하기 (선택)

에디터를 실행해 두고 로컬 MCP 서버를 Codex에 연결합니다. 별도 OpenAI API 키를 사용하는 에디터 내부 채팅은 없습니다. 다음 명령은 **사용자의 Codex 설정에 서버를 추가**하므로 직접 확인 후 실행하세요.

```bash
codex mcp add biadone-studio -- node --import /Users/joo/BiaDone/apps/Edu/editor/node_modules/tsx/dist/loader.mjs /Users/joo/BiaDone/apps/Edu/editor/server/mcp.ts
```

연결 후 Codex에서 예를 들어 다음처럼 지시합니다.

> Biadone Studio 프로젝트 목록을 읽고 내가 고른 프로젝트를 열어 줘. 3번 장면을 세 단계 그래픽으로 정리하되 다른 장면과 잠금은 유지해 줘. 수정 후 품질 검사를 실행해 줘.

도구는 프로젝트·장면 읽기, 검증된 편집 명령, 자막 가져오기, 품질 검사, 출력 시작과 작업 조회를 제공합니다. 수정에는 최신 리비전이 필요합니다. 편집 결과가 에디터에 자동 반영됩니다. 출력 시작과 실제 완료는 다르므로 Codex도 작업 상태를 끝까지 확인해야 합니다. 전역 Codex 설정은 이 프로젝트를 만드는 과정에서 변경하지 않았습니다.

## 저장과 백업

```text
data/projects/<project-id>/
  project.json       현재 편집 정보
  assets/            가져온 미디어 복사본
  revisions/         복원 가능한 편집 기록
data/jobs/<job-id>/
  job.json           작업 상태와 고정된 프로젝트
  output/            MP4 · 검증 결과 · 전사 결과 · 장면 초안
```

`data/` 폴더 전체를 복사하면 미디어와 작업 결과를 함께 백업할 수 있습니다. **편집 정보 JSON 받기에는 미디어가 포함되지 않습니다.** 다른 컴퓨터로 옮길 때는 JSON 하나가 아닌 자료 폴더도 함께 보관하세요. 기존 Edu의 `Sources/`, 기존 영상과 전사 결과는 가져오기 원본으로만 사용합니다.

저장은 원자적 교체와 리비전 검사로 보호합니다. 다른 창이나 Codex가 동시에 수정하면 충돌을 알리고 현재 초안을 보존합니다. 앱을 다시 열었을 때 중단된 작업은 실패 상태로 복구해 재시도할 수 있습니다.

## 로컬 음성 모델

현재 작업 환경의 `../.video-build/venv/bin/python`과 기존 faster-whisper small 모델을 탐지합니다. 설치된 모델만 사용하고 자동 다운로드하지 않습니다. 모델이 없으면 SRT·VTT·JSON 가져오기와 직접 자막 편집을 사용할 수 있습니다.

필요한 경우 실행 환경 변수 `STUDIO_PYTHON`, `STUDIO_WHISPER_MODEL`, `STUDIO_CHROME`, `STUDIO_FFMPEG`, `STUDIO_FFPROBE`, `STUDIO_PORT`, `STUDIO_DATA_DIRECTORY`로 경로·포트를 지정할 수 있습니다. MCP의 `STUDIO_URL`은 실행 중인 에디터 주소입니다. 화면의 Codex 연결 명령은 실제 포트와 앱 경로를 사용합니다. `.env` 파일은 만들거나 수정하지 않습니다. 파일 가져오기·전사·수동 편집·렌더링은 로컬에서 처리합니다. 사용자가 Codex 장면 생성을 요청할 때에만 위에 설명한 대본·설정 정보를 전달합니다.

## 검증

```bash
npm run typecheck
npm run lint
npm test
npm run build
npm run qa
npm run qa:scenes
```

`qa`는 임시 데이터 폴더와 별도 로컬 포트를 사용해 실제 Chromium에서 편집·저장·충돌·잠금·소스 가져오기·한국어 전사·출력을 검증합니다. 현재 Edu의 원본 음성과 슬라이드를 읽기 전용 fixture로 사용합니다. 브라우저 스크린샷과 JSON 결과 경로를 출력합니다. `-- --skip-render`를 붙이면 영상 출력만 건너뜁니다.

설계: [TECH_SPEC](docs/TECH_SPEC.md), [구현·검증 계획](docs/IMPLEMENTATION_PLAN.md), [디자인 기준](docs/DESIGN.md), [실제 검증 기록](docs/QA_REPORT.md).

`qa:scenes`는 명시적으로 주입한 검증용 생성기를 사용해 구성·생성·적용·충돌·취소·재시도의 UI를 확인합니다. 실제 AI 실행 검증은 `npm run qa:scenes -- --live-codex`로 구분하며 기존 Codex 로그인을 사용합니다. 모든 QA 프로젝트는 임시 데이터 폴더를 사용합니다.

장면 구성의 큰 분할 설정·전체 유형 선택·공통 연출 폼은 제거했습니다. 새 전사는 기존 장면 구성을 유지하며 자막을 추가합니다. 장면별 필수 요구사항은 4,000자까지 입력하며 AI의 편집 메모와 별도로 저장됩니다.
