# Biadon Edu — 내 사업을 위한 제작 스튜디오

제공된 커리큘럼을 인터랙티브 HTML과 100초 모션그래픽으로 제작했습니다. 따뜻한 종이색, 코발트, 얇은 선, 실제 업무 문서를 닮은 결과물로 구성했습니다.

## 바로 열기

- [인터랙티브 HTML](index.html): 과정 탐색, 상세 설명과 결과물, 나의 학습 경로 구성·저장.
- [모션그래픽 MP4](Biadon-Edu-Curriculum-1080p.mp4): 100초, 1920×1080, 30fps, H.264/AAC. 약 6.2MiB.
- [모션 프레젠테이션](motion.html): 같은 영상을 만드는 애니메이션을 브라우저에서 재생·탐색·챕터 이동. 소리 켜기와 전체 화면 지원.

HTML은 폴더 전체를 함께 두고 `index.html`을 브라우저로 열면 됩니다. 설치나 로그인 없이 실행되며 폰트·배경음도 포함되어 있습니다. MP4는 별도 영상 플레이어에서도 재생됩니다. 영상은 화면 내 한국어 설명과 직접 합성한 배경음으로 구성했으며 내레이션은 없습니다.

## HTML 구성

- 한눈에 보기: 종이 결과물을 눌러 해당 과정을 엽니다.
- 과정 탐색: 상세 패널의 **배우는 내용 / 가져갈 결과물** 두 탭에서 내용을 확인합니다.
- 나의 학습 경로: 필요한 과정을 선택하고 교육 시간을 합산합니다.

‘직접 해보기’ 탭과 화면 내 예제 기능은 요청에 따라 제거했습니다. 교육 과정 자체의 실습 설명과 결과물은 원문대로 유지합니다. 선택한 과정은 이 브라우저에 저장하며 텍스트 파일로 내려받을 수 있습니다.

## 내용 보존

원문의 과정 설명, 실습 결과물, 선택·연계 심화, AI 팀 세팅·운영 문단을 HTML 상세에 담았습니다. 영상은 전체 구조와 결과물을 간추린 소개입니다.

공통 기초 2시간은 기본 포함입니다. A 4시간, B 6시간, C 6시간, D 4시간, AI 업무팀 12시간을 모두 선택하면 **34시간 + 선택 E 별도 편성**입니다. E는 과제 범위에 따라 편성하며 전 과정 공통 운영 내용은 추가 시간으로 합산하지 않습니다. 교육 시간은 현재 편성안 기준입니다.

## 수정할 파일

| 파일 | 역할 |
| --- | --- |
| `curriculum.js` | HTML의 전체 과정 설명·시간·결과물 |
| `index.html`, `styles.css`, `app.js` | 인터랙티브 화면, 종이 레이어, 과정 상세와 경로 기능 |
| `motion.html`, `motion.css`, `motion.js` | 모션 플레이어, 장면별 문구·배치·시간·움직임 |
| `assets/PretendardVariable.woff2` | 로컬 한글 폰트, 함께 포함한 라이선스 참조 |
| `assets/studio-score.wav` | 직접 합성한 100초 배경음 |
| `scripts/` | 음원 생성, 프레임 렌더·MP4 출력, 영상 검증 |

HTML 과정 내용을 수정할 때는 `curriculum.js`를 바꿉니다. 영상 문구와 타이밍은 `motion.js`에서 별도로 수정한 뒤 다시 내보냅니다. 설치된 Edu 편집기의 Playwright와 로컬 Chrome·FFmpeg를 재사용하며 새 프로덕션 의존성은 추가하지 않았습니다.

이 Edu 작업 공간에서 영상을 다시 생성하는 명령:

```sh
node output/biadon-edu-curriculum/scripts/render-video.mjs
.video-build/venv/bin/python output/biadon-edu-curriculum/scripts/verify-video.py
```

렌더러는 기본 로컬 Chrome·FFmpeg 경로를 사용하며 `BIADON_CHROME`, `BIADON_FFMPEG`로 경로를 지정할 수 있습니다. MP4와 브라우저 재생은 동일한 `window.renderAt(seconds)` 함수로 화면을 만듭니다.

IAB 호출 결과가 `Browser is not available: iab`여서 Playwright와 시스템 Chrome의 별도 임시 프로필로 검사했습니다. 사용 중인 Chrome 프로필은 건드리지 않았습니다. 정적 HTML이므로 별도 빌드·TypeScript·lint 설정은 없으며, JavaScript 구문 검사는 모두 통과했습니다. 모바일은 브라우저의 해당 뷰포트에서 확인한 결과이며 실제 휴대폰·Safari 실기기 검증은 포함하지 않습니다.

HTML 수정 검증은 [html-verification.json](html-verification.json), 영상 검증 수치는 [video-verification.json](video-verification.json), 렌더 정보는 [render-info.json](render-info.json)에 있습니다. 기존 `editor/`, `Docs/`, `Sources/`와 배포 중인 사이트는 수정하지 않았습니다. 이번 로컬 산출물을 열기 위해 추가 승인은 필요하지 않습니다.

## 콘셉트와 구현 비교

설계 기준: [첫 화면 콘셉트](design/overview-concept.png), [과정 상세 콘셉트](design/detail-concept.png), [제작 방향](design/DIRECTION.md). 콘셉트 이미지는 초기 설계 기록이며, 현재 상세 화면은 ‘직접 해보기’를 제거한 두 탭입니다. 이미지 생성은 built-in `image_gen`을 사용했으며 [프롬프트](design/imagegen-prompts.txt)를 함께 보관했습니다. 실행 화면의 글자·버튼·문서·선 그림은 실제 HTML/CSS/SVG입니다.

최종 콘셉트와 실제 스크린샷을 `view_image`로 대조했고, 콘셉트 이미지의 실제 크기인 1536×1024에서도 확인했습니다.

| 비교 항목 | 확인·조정 |
| --- | --- |
| 문구 | 브랜드·상단 탐색·주 제목·소개·두 CTA·학습 흐름 문구 유지 |
| 배치 | 왼쪽 설명/오른쪽 종이 작업물, 하단 3단계 학습 흐름 유지 |
| 색 | 종이색 `#f5f4ee`, 잉크 `#222820`, 코발트 `#2340ff`, 연두·살구 고정 |
| 서체 | Pretendard Variable로 통일. 두 번째 콘셉트의 세리프는 첫 콘셉트에 맞춰 수정 |
| 결과물 | 소개 페이지·매출표·홍보물·계산기·문의 흐름의 종이 레이어를 코드로 구현 |
| 겹침·간격 | 계산기 제목·합계 가림, 팀 설명과 역할 표 겹침, 영상 보조 안내 겹침 수정 |
| 작은 화면 | 세로 재배치, 상세 패널 스크롤, 계산기 내부 여백·한글 줄바꿈 조정 |
| 아이콘 | 파란 B, 단순 화살표와 선 그림의 굵기·대비 일관성 확인 |

첫 화면 핵심 문구 대조에서 누락·추가 변경은 없습니다. 실습 표시는 예시임을 명확히 했고 공통 운영 내용을 여는 하단 링크를 추가했습니다. 의도한 차이는 반응형 글자 크기, 선 그림 단순화, 실제 내용을 모두 담기 위한 상세 패널의 길이와 배경 흐림입니다. 이 차이를 제외한 구조·색·서체·레이어 구성을 설계 콘셉트와 비교 검증했으며, 확인된 시각적 겹침은 해소했습니다.

후속으로 실제 브랜드 로고·사업 사진·문의 채널을 반영하거나 세로형 홍보 영상으로 편집할 수 있습니다.
