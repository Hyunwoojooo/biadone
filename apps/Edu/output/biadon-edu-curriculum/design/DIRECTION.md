# Biadon Edu — 제작 스튜디오

목적: 제공된 3장 커리큘럼을 따뜻한 편집 디자인의 인터랙티브 HTML과 100초 모션그래픽으로 각각 전달한다.

## 제작 범위

- `index.html`: 한눈에 보기, 과정 탐색, 나의 학습 경로. 원문 설명을 모두 보존하고, 과정 상세 종이 패널에서 배우는 내용과 결과물을 제공한다.
- `motion.html`: 100초 모션 프레젠테이션, 재생·탐색·챕터·음악 제어. 같은 결정적 프레임 함수를 MP4 렌더에 사용한다.
- `Biadon-Edu-Curriculum-1080p.mp4`: 1920×1080, 30fps, 100초. 직접 만든 배경음, 화면 내 한국어 설명. 내레이션 없음.
- 기존 editor, Docs, Sources와 배포 중인 사이트는 변경하지 않는다. 의존성 추가 없음.

## 시각 기준

기준 콘셉트 `overview-concept.png`. 사용자의 추가 요청에 따라 첫 이미지의 사진·반짝이 장식을 제거한 두 번째 콘셉트를 적용한다. UI는 모두 실제 HTML/CSS와 선 그림이다. 생성 이미지는 설계 참고용이며 실행 화면의 배경으로 사용하지 않는다.

- 배경: 따뜻한 종이색 `#f5f4ee`를 고정한다.
- 글자: `#222820`, 브랜드 `#2340ff`, 연두 `#e4ef9b`, 살구 `#f5baa0`.
- Pretendard Variable 로컬 폰트. 큰 제목 56~64px, 본문 17~20px, UI 14~16px. 작은 화면에서 줄바꿈과 간격을 재배치한다.
- 사각 종이, 얇은 구분선, 작은 번호, 제한된 기울기와 부드러운 종이 그림자. 입체 렌더·그라데이션·로봇·반짝이·상시 부유 효과는 쓰지 않는다.
- 브랜드는 작은 파란 B 정사각형과 Biadon Edu. 기존 로고를 대체한다는 주장은 하지 않는다.
- 히어로 왼쪽 46%, 실제 문서처럼 보이는 결과물 오른쪽 54%. 하단 가로 학습 흐름.
- 결과물: 사업 소개 페이지, 매출 보고서, 홍보물, 견적 계산기, 문의→저장→알림. 숫자는 실습 예시로 명시한다.
- 과정 상세는 오른쪽 종이 패널, 작은 화면에서는 전체 높이 패널. 키보드와 ESC로 접근한다.

## 내용과 상호작용 기준

- 전체 원문: `curriculum.js`. 선택 E의 시간은 미정, 합산에서 별도 표시한다.
- 공통 기초는 경로에 기본 포함, 선택 과정과 심화 과정은 선택한다. 안전·운영 공통 과정은 추가 시간으로 합산하지 않는다.
- 배우는 내용/가져갈 결과물 두 탭, 경로에 담기·제거, 시간 합산, 경로 저장(텍스트 파일), 새로고침 시 경로 복원.
- 2026-10-26 수정: 사용자의 요청으로 ‘직접 해보기’ 탭과 예제 기능을 제거했다. 초기 콘셉트 이미지는 설계 이력으로 보존한다.
- reduced-motion, 모바일, 키보드 접근·포커스 복귀, 스크롤 복원, 로컬 파일 실행을 검증한다.

## 영상 타임라인

0–8초 도입 / 8–18초 공통 기초 / 18–26초 선택 A / 26–35초 선택 B / 35–45초 선택 C / 45–54초 선택 D / 54–63초 선택 E / 63–79초 AI 업무팀 / 79–90초 운영 카드 / 90–100초 마무리.

제목 한 개, 결과물 한 묶음, 보조 설명 한 묶음으로 장면을 제한한다. 종이가 도착·정렬·수정·전달되는 동작을 사용하고 핵심 설명은 최소 4초 고정한다. 모든 영상의 음원은 로컬에서 직접 합성한다.
