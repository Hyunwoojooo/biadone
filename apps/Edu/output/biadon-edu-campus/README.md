# Biadon Edu · 수업의 문을 열어보세요

사용자가 제공한 새 커리큘럼과 사무실 일러스트를 바탕으로 만든 공간 탐색형 HTML입니다. 일곱 방을 걸어서 방문하면 수업 내용과 완성할 결과물이 펼쳐집니다.

## 열기

함께 제공한 `Biadon-Edu-Campus.html`을 Chrome에서 열면 됩니다. 이미지·글꼴·스크립트가 모두 들어 있으므로 인터넷 연결이나 서버가 필요 없습니다. 소스를 수정할 때는 이 폴더의 `index.html`을 열어 확인할 수 있습니다.

## 조작

- 지도를 클릭한 다음 방향키 또는 WASD로 걷습니다.
- 문 앞에서 Enter를 누르거나 문까지 걸어가면 안내가 열립니다.
- Esc 또는 ‘방에서 나오기’로 지도로 돌아옵니다.
- 지도 표지판이나 수업 목록을 누르면 복도를 따라 자동으로 걸어갑니다. 방향키를 누르면 직접 조작으로 바뀝니다.
- 작은 화면에서는 방향 버튼을 누르고 있으면 움직입니다. 지도는 캐릭터를 따라갑니다. ‘전체 지도’와 확대·축소도 사용할 수 있습니다.
- ‘전체 커리큘럼’에서는 걷지 않고 각 과정의 내용을 바로 볼 수 있습니다.

‘둘러본 방’은 이번 페이지에서 열어 본 방을 표시합니다. 수강 완료나 학습 성취를 뜻하지 않으며 새로 열면 초기화됩니다.

## 수업 구성

기초, 선택 A–E, 심화까지 7개 방과 전 과정 공통 운영 안내를 담았습니다. 새 커리큘럼 이미지의 학습 항목 52개, 과정명, 결과물, 하단 주석을 반영했습니다. 선택 과정은 필요한 방을 자유롭게 고르면 됩니다. 비용·보안·복구는 모든 과정에 포함됩니다. ‘조회수 1만 회’는 도전 목표이며 성과 보장이 아니라는 원문 주석을 함께 표시합니다.

사용자 요청에 따라 지도 표지판·수업 목록·상세 안내·전체 커리큘럼에서 교육 시간과 횟수 표기를 제거했습니다. 원본 시간 정보는 `curriculum.js` 자료에만 보관합니다.

별도 ‘직접 해보기’ 탭이나 예제 도구는 없습니다. 각 방에서 배우는 내용과 완성할 결과물을 바로 읽도록 구성했습니다.

## 수정할 파일

| 파일 | 수정하는 내용 |
| --- | --- |
| `curriculum.js` | 수업명·시간·학습 항목·결과물 |
| `map-layout.js` | 문·표지판·보행 영역·자동 이동 경로 |
| `movement.js` | 방향키·충돌·입장·길찾기 |
| `campus.js` | 안내 화면·모바일 카메라·방문 표시 |
| `campus.css` | 화면 구성·색·글꼴·반응형 |
| `assets/` | 지도·캐릭터·로컬 글꼴 |

수정 후 `node scripts/build-standalone.mjs`를 실행하면 상위 폴더의 단일 HTML을 다시 생성합니다. 빌드 스크립트는 Node 기본 모듈만 사용합니다.

## 그림과 화면 구성

제공 이미지를 바탕으로 OpenAI 내장 이미지 생성 도구로 지도와 방문자 캐릭터를 따로 제작했습니다. 배경에 글자를 굽지 않고 방 이름·상세 내용·버튼을 실제 HTML로 구현했습니다. 글꼴은 Pretendard Variable이며 라이선스는 `assets/Pretendard-LICENSE.txt`에 있습니다.

`design/overview-concept.png`와 `design/detail-concept.png`가 화면 구성 기준입니다. 지도·복도·방 배치, 얇은 선, 따뜻한 나무 색, 오른쪽 목록, 두 칸 상세 안내를 구현에 반영했습니다. 실제로 걸어 다닐 수 있도록 앞쪽 방의 복도 쪽 벽을 열었으며, 작은 화면은 제목과 지도를 세로로 나누고 캐릭터를 따라가는 카메라를 사용합니다. 생성 프롬프트는 `design/IMAGE_PROMPTS.json`에 있습니다.

### 방의 작업이 보이는 두 번째 지도

현재 HTML은 `assets/campus-world-v2.png`를 사용합니다. B–E가 같은 사무실처럼 보이던 문제를 방별 대표 작업과 큰 결과물로 구분했습니다.

| 방 | 공간에서 보이는 작업과 결과물 |
| --- | --- |
| B · 소개·문의 웹페이지 | 큰 웹페이지 설계도, 사이트 구조, 데스크톱·모바일 화면, 종이 와이어프레임 |
| C · 고객 문의 자동화 | 문의 접수함, 고객 카드, 분류함, 전화, 알림 벨로 이어지는 응대 흐름 |
| D · 매출 분석·보고서 | 상품별 차트·주간 추이·집계표, 계산기, 영수증, 비교하는 보고서 |
| E · 나만의 업무 도구 | 계산기 앱 시제품, 입력→처리→결과 모듈, 정리할 문서와 분류된 파일함 |

A의 촬영 스튜디오, 중앙 복도와 입구, 기초·심화 방의 구성을 유지했습니다. 이전 지도는 `assets/campus-world.png`에 보관했으며 수정 프롬프트는 `design/ROOM_IDENTITY_V2.json`에 있습니다.

## 검증 범위

`verification.json`에 자동 확인 결과를 기록했습니다. 이번 수정은 1536×1024와 390×844 화면에서 지도·목록·8개 상세 안내의 시간·횟수 제거, 본문 보존, 가로 넘침, 단일 HTML의 방향키 입장 등 56개 검사를 통과했습니다. 콘솔·실행 오류와 외부 요청은 0건입니다. 이전 이동·재입장·키 해제·모바일 방향 버튼 검사 기록도 함께 보관합니다. 내장 브라우저를 사용할 수 없어 임시 프로필의 Chrome과 Playwright로 로컬 파일을 확인했습니다. 외부 네트워크 요청이나 별도 서버는 필요하지 않습니다.

모바일 검증은 브라우저의 화면 크기·터치 환경을 사용했습니다. 실제 휴대폰과 Safari에서는 별도 확인이 필요합니다. 물리적인 3D 공간이 아니라 그림 위의 보행 영역과 문을 판정하는 2D 구현입니다.

기존 커리큘럼 HTML·영상, 에디터 및 원본 자료는 이번 결과물과 별도로 보존했습니다.
