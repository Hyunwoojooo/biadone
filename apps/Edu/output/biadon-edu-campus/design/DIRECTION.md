# Biadon Edu Campus

## 이번 버전의 기준

사용자가 2026-10-27 제공한 새 커리큘럼 이미지와 아이소메트릭 사무실 이미지가 기준이다. 기존 종이형 HTML과 영상은 수정하지 않는다. 이번 범위는 방향키로 캐릭터를 움직여 수업 방에 들어가는 HTML이다.

- `curriculum-source.png`: 과정명, 교육 시간, 52개 학습 항목, 결과물, 하단 주석 2개의 원본.
- `spatial-reference.png`: 공간·인물·그림체 참고.
- `overview-concept.png`: 실제 화면 구현 기준. 그림 지도, 조작 안내, 오른쪽 방 목록.
- 지도용 배경과 방문자 캐릭터는 별도 이미지 자산. 방 이름·조작·상세 내용은 HTML로 표시한다.

## 공간과 이동

7개 방: 기초 F / 홍보 콘텐츠 A / 웹페이지 B / 고객 문의 C / 매출 분석 D / 업무 도구 E / AI 업무팀 T. 비용·보안·복구 S는 상시 운영 안내이다.

넓은 중앙 복도에서 각 방의 문으로 연결한다. 평면 그림 좌표에서 발 위치로 보행 영역과 문을 판정한다. 방향키는 화면 상하좌우로 이동하며, Enter 또는 문까지 걸어 들어가면 상세 안내가 열린다. Esc로 나오면 문 앞에 서며 같은 문에 즉시 다시 들어가지 않는다. 방 표지판·방 목록은 복도를 따라 자동 이동하는 대체 조작이다.

키가 눌린 상태에서 창 전환·상세 열기·탭 숨김이 발생하면 입력을 해제한다. 상세 화면의 스크롤은 캐릭터를 움직이지 않는다. 모바일에는 누르고 움직이는 방향 버튼이 있고 카메라가 캐릭터를 따라간다. 메뉴·전체 과정 목록으로도 정보를 확인할 수 있다.

## 시각 시스템

- 화면 바탕 `#f7f7f3`, 잉크 `#222b32`, 주 색상 `#3437ee`.
- F 파랑 / A 하늘 / B 보라 / C 산호 / D 주황 / E 초록 / T 보라. 글자는 대비를 확보한 진한 색을 쓴다.
- 얇은 잉크 선, 자연스러운 나무 책상과 식물, 레퍼런스와 같은 절제된 사무실 일러스트.
- 로봇·반짝이·빛나는 효과·보상용 코인·경험치 표시는 넣지 않는다.
- Pretendard Variable. 로컬 파일에서도 폰트를 읽을 수 있도록 데이터 URL 글꼴 CSS를 사용한다.
- 데스크톱은 지도와 300px 안팎의 방 목록. 작은 화면은 지도 카메라·터치 조작과 방 목록을 세로로 배치한다.
- 방문자 그림은 투명 4방향×2프레임 시트. 움직일 때만 걷기 자세가 바뀐다.
- UI/UX 검색 결과의 일반 랜딩·다크 템플릿은 이번 공간 탐색형 화면과 맞지 않아 채택하지 않았다. 제공 이미지로 색·공간을 정하고 검증된 키보드 포커스·터치 크기·대비 지침을 적용한다.

## 방 안내

한 번에 배우는 내용과 결과물을 읽는 종이 안내 패널. 별도 ‘직접 해보기’ 데모는 없다. 공통 기초와 선택 과정, 심화 과정의 시간 조건을 그대로 표시하며 선택 E의 시간을 임의로 합산하지 않는다. A의 조회수 1만 회는 도전 목표이며 성과 보장이 아님을 명시한다.

## 구현 대조 기록 · 2026-10-27

핵심 상호작용은 방향키 → 기초 방 입장 → 안내 읽기 → Esc 퇴장 → 다른 방 표지판 선택 → 복도를 따라 도착하는 흐름으로 확인했다. 모바일은 방향 버튼의 누름·해제와 자동 이동을 확인했다. 안내를 읽던 중 다음 방으로 이동할 때 이전 경로에 먼저 재입장하던 경합과 단일 파일 생성 시 스크립트 치환 오류도 수정했다.

공간 구성과 정보 위계를 콘셉트에 충실하게 구현했는지 직접 대조했다. 남은 차이는 보행을 위한 열린 벽, 원문 시간 표기, 대비를 위한 단색 배지, 반응형 카메라 구성이다. 확인한 화면에 수정이 필요한 겹침이나 누락은 남아 있지 않다. 실제 휴대폰·Safari 검증은 별도 범위다.

## 시간·횟수 표기 제거

사용자 요청에 따라 지도 표지판, 수업 목록의 보조 문구와 접근성 이름, 방 상세의 헤더·시간 줄, 전체 커리큘럼의 시간 열을 제거했다. 시간 열이 빠진 전체 목록은 과정·결과물·내용 보기의 세 칸으로 정리했다. 시간 정보는 원본 데이터에만 보존한다. 아래의 시간 표시 관련 대조 기록은 이전 버전에 대한 기록이다.

## B–E 방의 역할 표현 수정

사용자 피드백: A는 촬영 장비로 홍보 콘텐츠라는 주제가 드러나지만 B–E는 비슷한 모니터와 책상으로 보여 제목과 공간이 잘 연결되지 않았다.

기존 지도에서 방 내부의 대표 소품과 사람의 작업을 수정했다. 현재 지도는 `assets/campus-world-v2.png`이다. B에는 웹페이지 설계도·사이트 구조·모바일 미리보기, C에는 문의 분류함·고객 카드·전화·알림 흐름, D에는 큰 분석 차트·집계표·영수증·보고서, E에는 계산기 앱 시제품·처리 모듈·파일 분류함을 배치했다. 같은 파란 모니터를 반복하던 표현을 줄이고 각 방에 큰 결과물을 두었다.

건물 외곽과 투명 캔버스는 1448×1086으로 유지했다. A·기초·심화의 배치와 중앙 보행 공간을 유지했으며 이동 엔진과 문 좌표는 변경하지 않았다. 방 이름이 없는 지도 원본에서도 네 방의 대표 작업이 구별되는지 확인했고, 실제 HTML의 1536×1024와 1366×768 화면에서 표지판·캐릭터·문의 위치를 대조했다. 표지판이 웹 설계도·알림 벨·계산기 앱을 가리지 않도록 B–E의 표지판 위치를 옮겼다. 기존 화면 콘셉트는 배치 참고용이며 방의 내부 표현은 이번 사용자 피드백을 우선한다. 새 지도 적용 후 53개 조작·내용 검사를 다시 통과했고, 마지막 표지판 조정 뒤 데스크톱·모바일 배치와 단일 HTML의 방향키 입장을 확인했다.
