# 방 안으로 들어가는 영상 · 연출 샘플

현재 HTML 캠퍼스를 그대로 보여주는 방식에서 벗어나, 주인공 뒤를 따라 문을 통과한 다음 AI 직원들의 작업을 관찰하는 30초 장면을 새로 제작한다. 전체 2~3분 안내 영상의 첫 방에 적용할 연출을 검토하는 샘플이다.

## 시각 기준

- 흰 벽 `#fafaf7`, 잉크 `#242626`, 파랑 `#3437ee`, 옅은 파랑 `#dfe8fa`, 종이 노랑 `#f2edcf`, 회녹색 `#a6b9ac`.
- Pretendard Variable. 공간 안의 간판과 작업물에 글을 배치하고, 화면 위에는 해당 작업의 짧은 설명만 둔다.
- 얇은 외곽선과 평면색을 사용한 3D 세트. 뒤통수·어깨에서 시작하는 카메라, 실제 문턱 통과, 작업 동작을 잡는 근접 컷으로 깊이를 만든다.
- 원본 지도, 과정 목록 패널, 웹페이지 UI, 시간·회차, 결과물 하단 푸터는 사용하지 않는다.
- 주인공은 제공받은 캐릭터의 짙은 머리·흰 상의·짙은 바지 실루엣을 참고한 입체 시안이다. 정면 원본 일러스트를 3D 모델로 복원했다고 주장하지 않는다.

## 컷 구성

| 구간 | 카메라와 동작 | 화면에서 읽히는 내용 |
| --- | --- | --- |
| 0–3초 | 주인공의 뒷머리와 어깨. 문을 향해 걷기 시작 | 홍보 콘텐츠 제작실 간판 |
| 3–8초 | 문이 열리고 카메라가 주인공 뒤에서 문턱을 통과 | 안에서 일하는 세 Agent |
| 8–14초 | 실내로 들어와 옆으로 돌아 전체 작업 공간 공개 | 홍보 콘텐츠 만들기 |
| 14–17초 | 기획 Agent와 제목 메모에 접근 | 첫 3초·제목·썸네일 |

| 22–26초 | 검수 Agent의 펜·체크·수정 동작 | 반응을 확인하고 직접 고치기 |
| 26–30초 | 세 직원이 계속 작업하는 실내 전경 | 만들고, 써보고, 스스로 고칩니다. |

## 제작과 검증

Remotion 4.0.538의 공식 ThreeCanvas와 React 19에 맞는 React Three Fiber 9를 사용한다. 모든 동작은 프레임으로 계산한다. 기존 한국어 남성 내레이션의 도입·홍보 과정 클립을 재사용하고, 발소리·종이·타이핑·짧은 음악은 로컬에서 합성한다. 새로운 유료 음성·이미지·영상 생성 API는 사용하지 않는다.

대표 컷을 먼저 렌더링해 문턱 통과·카메라 가림·글자 표시를 확인한다. 이후 완성 MP4 전체 디코드, 프레임 수, 길이, 오디오 음량과 원본 보존을 확인한다. 원본 HTML, 이전 두 영상, 사용자 캐릭터 원본 파일의 변경 여부는 별도 해시로 검증한다.
