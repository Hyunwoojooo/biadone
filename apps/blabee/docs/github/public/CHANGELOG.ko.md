# 변경 이력

[English](CHANGELOG.md) · **한국어**

앱 업데이트와 공개 연동 소스 업데이트를 아래에서 구분해 기록합니다.
명시적으로 미배포라고 표시한 항목은 초안이며, 앱이 공개되면 배포일과 다운로드 링크를 추가합니다.

공개된 앱 버전의 이력은 2026-10-19에 정리했습니다. 추가 로컬 빌드 기록은
2026-10-20에 검토했으며, 아래 별도 항목에 수록했습니다.
앱 업데이트의 날짜는 GitHub 게시일입니다. 추가 빌드 이력의 날짜는 원본 기록에
명시된 제작·검증·작업 완료 날짜이며, 한국 표준시를 사용한 항목에는 KST를 표시했습니다.
이 날짜는 공개 배포일을 뜻하지 않습니다.
과거 항목은 당시 동작과 제한을 설명하며 현재 설치·호환성 안내를 대신하지 않습니다.
현재 다운로드와 설정 방법은 [README](README.ko.md)를 참고하세요.

## 앱 업데이트

### r88

**배포일:** 2026-10-26. **앱 버전:** 0.1.0 (build 88, arm64).
Developer ID 서명과 Apple 공증을 완료했습니다.
[r88 다운로드](https://github.com/Hyunwoojooo/biadone/releases/tag/blabee-v0.1.0%2Bbuild.88).

#### 개선

- Codex **0.164.0**의 Plugin 연결과 선택 전달을 지원합니다. 이 버전에서
  `codex_native_version_unqualified`로 제출이 차단되던 원인을 수정했습니다.
- 관리형 Codex의 작업 공간 연결, 세션 재개, 업데이트 처리에 공식 0.164.0
  런타임을 등록했습니다.
- 지원되는 Pet 권한 승인을 위해 공식 0.164.0 macOS arm64 실행 파일을
  등록했습니다. 기존 신뢰·요청 검증은 유지됩니다.
- Hook 상태 안내를 명확히 했습니다. Codex 검사 중 기존 신뢰 정보가 갱신될 수
  있으며, Plugin 내용이 변경되면 `/hooks`에서 다시 검토해야 할 수 있습니다.

#### 업데이트 안내

- r88을 설치해야 새 지원이 적용됩니다. 실패한 선택은 자동으로 재전송하지
  않습니다. 새 카드를 요청하거나 원래 대화에서 작업을 명시적으로 이어 주세요.
- 이번 호환성 수정은 다른 전달 실패 뒤 **작업 중** 표시가 남는 일반적인 상태
  처리를 변경하지 않습니다.

**검증 범위:** Swift 집중 회귀 775개, 계약·호환성 233개, 패키징 270개,
공식 Codex 패키지의 Swift catalog 검사와 실제 번들 Claude payload 검사를
통과했습니다. 선택적 패키징 검사 1개는 제외됐습니다. 서명·Apple 공증·공증 티켓·
Gatekeeper 검사도 통과했습니다. 새 Mac 설치, 설치 앱의 업데이트·재실행, OAuth,
실사용 Hook → Pet → queue → 작업 완료는 별도 검증 대상입니다.

### r87

**배포일:** 2026-10-21. **앱 버전:** 0.1.0 (빌드 87, arm64).
Developer ID 서명과 Apple 공증을 완료했습니다.
[r87 다운로드](https://github.com/Hyunwoojooo/biadone/releases/tag/blabee-v0.1.0%2Bbuild.87).

#### 개선

- 저장된 폴더 설정 없이 처음 Codex 연결을 시작하면, 별도 폴더 선택 창 없이
  Mac 계정의 홈 폴더와 하위 폴더를 기본 작업 범위로 사용합니다.
  기존 폴더 설정과 사용자가 의도적으로 비워 둔 목록은 보존합니다.
- 설정의 Codex 항목을 하나의 연결 요약으로 정리하고, 상세 검사는 연결 설정에서
  확인할 수 있도록 했습니다.

#### 수정

- 느린 Codex Plugin 검사에 더 긴 대기 시간을 제공합니다. 읽기 전용 조회가
  시간 초과된 뒤 안전하게 종료된 경우, 이후 실행을 계속 막는 기록을 남기지 않습니다.
- 다른 Claude·Codex 카드가 선택되어 있어도 새 Claude 연결을 다시 확인할 수
  있습니다. 현재 보고 있는 카드는 유지합니다.
- 연결 상태 갱신에 실패한 뒤 설정에 이전의 연결 완료 표시가 남는 문제를 수정했습니다.
- 갱신된 zsh 자동 연결 설정은 `claude`를 실행할 때 Blabee 런처를 우선 사용하여,
  로그인 시작 과정에서 PATH가 바뀌는 경우에도 적용합니다.
  기존 사용자 alias와 함수는 보존합니다.
- Claude가 시작되기 전에 업데이트 잠금으로 자동 연결이 막히면,
  Blabee 연결 없이 검증된 원래 Claude CLI의 실행을 한 번 시도합니다.

#### 업데이트 안내

- 기존 Claude 자동 연결 사용자는 r87을 설치한 뒤 **자동 연결 설정 업데이트**
  또는 **Claude 연결**을 한 번 실행하고 새 zsh 창을 여세요.
  앱 설치만으로 기존 셸 설정이 갱신되지는 않습니다.
  이후의 사용자 지정 셸 정의는 여전히 자동 연결보다 우선할 수 있습니다.
- 기존 Codex 시간 초과 차단이 남아 있으면 설정에서 **Codex 실행 다시 검사**를
  한 번 실행하세요. 이전 선택은 자동으로 재전송하지 않습니다.

기존 사용자 프로필은 보존합니다. Blabee는 계속 Google 또는 GitHub 로그인이
필요하며, Codex와 Claude Code는 각 서비스의 계정을 사용합니다.

**검증 범위:** 격리된 집중 회귀 검사를 통과했습니다.
설치 후 실제 대화의 연결·선택·실행은 별도 검증이 필요합니다.

### r86

**배포일:** 2026-10-19. **앱 버전:** 0.1.0 (빌드 86).
Developer ID 서명과 Apple 공증을 완료했습니다.
[r86 다운로드](https://github.com/Hyunwoojooo/biadone/releases/tag/blabee-v0.1.0%2Bbuild.86).

#### 개선

- 첫 실행의 설정 화면에서 진행을 막는 서비스·내부 저장소 문제를 파악하고
  해당 문제에 필요한 복구 동작을 표시합니다.
- 연결 준비가 된 도구와 확인이 필요한 도구를 구분해 안내합니다.
  Claude 설정이 미완료여도 가능한 다음 Codex 연결 동작이 가려지지 않습니다.
- 서비스가 비활성 상태이면 활성화 동작을 제공하고, 오래된 서비스 등록은
  재시작 전에 별도로 제거할 수 있도록 안내합니다.

#### 수정

- 기존 터미널 설정 항목이 Blabee가 관리하는 것으로 검증된 경우, 연결 버튼으로
  누락된 Claude 자동 연결 런처를 복원할 수 있습니다. 수정되었거나 충돌하는
  설정 항목은 여전히 검토가 필요합니다.

**복구 안내:** 내부 저장소를 새로 시작하려면 확인이 필요하며, 잃어버린 선택 이력은
복원되지 않습니다. 이 업데이트를 설치하는 것만으로 저장소가 초기화되지는 않습니다.

- Claude 진단 출력 오류 처리와 오래된 연결 기록의 복구를 보완했습니다.

다시 시도해야 했습니다. Claude 연결을 유지한 상태의 서비스 교체는 지원하지 않았습니다.

## 추가 빌드 이력

다음은 로컬·내부 테스트·공증 빌드에 남아 있는 변경 기록입니다.
검토한 기록만으로는 해당 빌드의 **공개 배포 여부를 확인하지 못했으며**,
추가 다운로드 릴리스로 안내하는 항목이 아닙니다. 서명·공증·테스트 통과만으로
공개 배포나 실제 사용자 환경의 동작 성공을 뜻하지는 않습니다.
릴리스 메모·검증 보고서·당시 작업 기록에서 빌드 번호 또는 산출물 식별자와 직접 연결할 수 있는
변경 내용만 수록했으며, 날짜 근거가 없으면 미확인으로 표시했습니다.
