# Reporting security issues

For a suspected credential exposure, cross-session action, duplicate execution
or permission-boundary bypass, use the repository's **Security → Report a
vulnerability** option. If it is unavailable, open an issue asking for a private
reporting channel, without including the vulnerability details. Please do not
post tokens or exploit details in a public issue.

Include the affected Blabee build, provider/CLI version, operating system,
expected behavior and a minimal synthetic reproduction. Remove names, project
paths, credentials, prompts and transcript contents unless privately requested.

This repository covers only the published integration components. See
[PUBLIC_SCOPE.md](PUBLIC_SCOPE.md) for the app/service boundary. No response
time or bounty program is promised by this document.
