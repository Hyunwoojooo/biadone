# 통합 최초 연결 작업 상태

기준일: 2026-09-23. 사용자가 계획에 따른 구현을 승인했다. 통합 설정의 앱·브릿지 소스 구현과 격리 회귀 검증을 완료했으며, 공개 통합 배포와 실제 신규 Mac 수용 검증은 미완료다. 설치된 앱·사용자 계정·실제 세션을 교체하거나 변경하지 않았다.

## 구현 결과

- 마지막 온보딩 단계와 설정의 연결 탭이 같은 `PetConnectionSetupView`를 사용한다. 도구 발견 → 사용자 선택 → 연결하기 → 현재 설정 재검사의 한 흐름으로 조립했다.
- Claude-only는 Codex 설치·Hook 신뢰·프로젝트 등록을 요구하지 않는다. Codex는 사용자가 선택한 작업 폴더를 첫 서비스 실행 전에 저장한다.
- 설정 저장과 현재 세션 준비·카드 수신을 구분한다. 선택한 모든 도구가 configured이고 현재 서비스 응답이 검증됐을 때 설정을 완료할 수 있다. 실제 명령 실행 완료를 뜻하지 않는다.
- 한 도구 실패가 다른 도구 설정을 되돌리지 않는다. 실패 도구를 명시적으로 나중에 연결하거나 현재 상태부터 재시도할 수 있다. 완료 기록 대신 선택 의도만 UserDefaults에 저장한다.
- 온보딩의 Claude 준비는 읽기 전용 `firstRunSetupSnapshot`과 현재 directory를 관찰한다. 정상 소비자 heartbeat, 카드 선택·claim, 터미널 자동 열기를 시작하지 않는다.
- 초기 화면 두 영역의 경쟁 조회를 공통 진입점으로 합쳤다. 같은 polling 증거에는 UI 변경 알림을 반복하지 않는다.
- Codex 경로 신뢰 오류에 실패 종류와 컴포넌트 진단을 추가했다. 기존 신뢰 검사·버전 정책은 유지한다.
- 공개 빌드는 실제 HTTPS 약관·개인정보 URL과 명시적인 문서 버전이 없으면 원본/staged plist 단계에서 차단한다. 내부 더미 약관 및 Claude 개발 모드 공개 차단은 유지한다.

## 검증

상세 명령·로그·실패 분류는 [QA_REPORT.md](QA_REPORT.md)를 따른다.

- Swift 전체: 1,566개 실행에서 4개 이슈 발견. 새 상태의 중복 발행 2건 수정, 변경된 UI 검사 1건 갱신, 기존 Codex 0.156 지원과 맞지 않던 테스트 기대값 1건 정합화.
- 최종 변경 관련 Swift 재검사: **259/259 통과**. 전체 1,566개를 수정 후 다시 전부 실행한 것으로 보고하지 않는다.
- 패키징: 최초 227개 중 219 통과, 환경 제한 7 실패, 1 skip. 환경 제한 7건은 권한 있는 격리 검사로 **7/7 통과**.
- Claude 자동 연결 Node: **19/19 통과**, JS syntax: **50개 파일 통과**.
- 새 연결 화면 8개, 첫 실행 화면 16개 렌더 생성. Claude 단독 준비·부분 준비·좁은 첫 실행 화면을 육안 확인했다.
- 이번 변경 대상 `git diff --check` 통과. 새 production 의존성, Engine/Contracts/DB schema 변경 없음.
