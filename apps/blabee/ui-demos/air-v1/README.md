# Blabee Air — 독립 UI 데모

문서: [Glass v5.1 UI 방향](../../docs/GLASS_V5_1_UI_PLAN.md)

현재 Blabee를 교체하기 전에 재질, 곡률, 카드, 상세와 설정 흐름을 검토하는 데모입니다. 배경은 비교용 예시이며, Air의 인상은 유리 표면·가벼운 경계·옅은 하늘빛과 크림빛으로 표현했습니다.

## 열기

- **브라우저 비교 스튜디오:** 실행 중인 로컬 서버의 <http://127.0.0.1:4327>.
- 서버 없이 보려면 이 폴더의 `index.html`을 브라우저로 엽니다.
- **Mac 바탕화면 위에서 보기:** `native/build/Blabee Air Demo.app`을 엽니다. 이번 작업에서 이 Mac용으로 빌드했습니다. 배포용 공증 앱이 아닙니다.

서버를 다시 시작하려면 프로젝트 루트에서:

```sh
python3 -m http.server 4327 --bind 127.0.0.1 --directory ui-demos/air-v1
```

Mac 데모를 다시 빌드하려면 Xcode Command Line Tools가 있는 Mac에서:

```sh
python3 ui-demos/air-v1/native/build.py
```

## 살펴볼 순서

1. **12 · 선택지 4개:** 카드를 고르고 `선택 전달하기`를 누릅니다. 결과는 자동 성공하지 않으며, 아래 `결과 예시`에서 바꿉니다.
2. **13 · 긴 한글 / 10 · 작업 전체 상세 / H1 · 누르는 동안 상세:** 같은 폭에서 내용을 읽고 내부를 스크롤합니다.
3. **14 · 작업 이동:** Blabee·Blabase·BiaDone 사이를 이동합니다. 이동하면 이전 선택 표시가 지워집니다.
4. **03 · 단축키 설정:** 변경 → 다른 탭 → 복귀 → 저장 또는 취소를 비교합니다.
5. **24 · 명령 승인 / 19 · 연결 오류 / U1–U4 · 업데이트:** 명령·대상·오류·복원 결과의 표현을 검토합니다.

35개 상태를 왼쪽 목록에서 고를 수 있습니다. 좁은 화면에서는 상단 `화면` 목록을 사용합니다. `초기 상태`는 데모 데이터와 설정을 초기화합니다.

설정 하단의 `업데이트 확인`을 누르면 **02**에서는 `최신 버전`, **U1**에서는 `업데이트 가능`을 3초간 표시하고 원래 문구로 돌아옵니다. 다시 누르면 마지막 클릭부터 3초를 셉니다. 버전 정보는 예시이며 실제 조회는 하지 않습니다. U1의 별도 `업데이트` 버튼으로 다운로드 화면 예시를 볼 수 있습니다.

## 비교할 수 있는 항목

| 항목 | 선택 |
| --- | --- |
| 테마 | 밝게 / 어둡게 |
| 재질 | Air / 중성 유리 / 불투명 |
| 배경 | 안개 / 밝은 문서 / 어두운 터미널 / 노을 |
| 곡률 | 38 시안 / 20.2 기존 값 비교 |
| 카드 클릭 | 선택 후 전달 / 즉시 전달 |

기본 폭은 460 CSS px이며 Mac 데모는 460pt입니다. 작은 브라우저에서는 가용 폭에 맞춥니다. 38pt 곡률은 검토용 후보입니다.

Mac 데모에서는 메뉴바의 `화면`, `표현`, `결과 예시`를 사용합니다. 설정의 저장은 해당 데모 프로세스 안에서만 유지됩니다.

## 단축키

데모 화면에 포커스가 있을 때만 적용됩니다. 전역 단축키를 등록하지 않습니다.

| 키 | 동작 |
| --- | --- |
| Option + 1–4 | 해당 선택의 전달 중 화면으로 이동 |
| Control + 1–4 누르기 | 상세 미리보기; 보조 키를 놓으면 닫기 |
| Option + ← / → | 14번 화면의 대기 작업 이동 |
| Command + 1 / 2 / 3 | 승인 화면에서 이번만 승인 / 거절 / Codex에서 선택의 모의 동작 |
| Escape | 상세 또는 대화상자 닫기, 그 외 패널 숨기기 |

브라우저·macOS가 먼저 사용하는 조합은 전달되지 않을 수 있습니다. 이 경우 H1 화면이나 버튼으로 모양과 흐름을 확인합니다. 입력 필드에서 선택 단축키는 실행되지 않습니다. 전역 Enter 동작은 없습니다.

## 데모의 경계

- 모든 프로젝트, 세션, 버전, 연결 상태와 결과는 예시입니다.
- 실제 승인·명령 실행·Codex 전달·업데이트 다운로드·앱 종료·세션 복원은 하지 않습니다.
- 네트워크 요청과 영속 저장이 없으며 CSP도 연결 요청을 차단합니다.
- Mac 앱의 네이티브 연결은 창 크기를 전달하는 것뿐입니다. WebKit 임시 데이터 저장소를 사용합니다.
- 제품 소스, 설치본, 서비스, 설정 파일을 변경하지 않습니다.
- Mac 데모는 클릭과 키 입력을 검토하기 위해 포커스를 받습니다. 제품의 비활성 패널 동작과 전역 단축키는 별도 통합 단계에서 검증해야 합니다.

화면 피드백을 반영한 뒤 제품 UI와 백엔드 연결을 진행합니다. 검증 기록은 [QA_REPORT.md](QA_REPORT.md)에 있습니다.
