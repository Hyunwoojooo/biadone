# Biadone 전체 화면 스타일 비교

상태: 2026-10-27 사용자가 **A 정돈된 구조**를 선택했다. 공통 원칙은 ../../design-system/SCREEN_STYLE.md, 핵심 구조값은 screen-style.tokens.json에 반영했다. 이 폴더의 다른 후보는 비교 기록으로 보존한다.

목적: 확정된 로고·색상·서체로도 달라지는 화면의 인상을 같은 회사 첫 화면과 Edu 슬라이드로 비교한다. 전체 홈페이지나 실제 강의의 제작 단계는 아니다.

## 이미 확정한 조건

브랜드는 유능하고 든든하며 유연해야 한다. 밝은 A 팔레트, Pretendard, 간격 2.83의 B 심벌, B 균형형 이름 조합을 유지한다. 대표 블루 #2858F0, tint #EEF5FF, ink #23314D, white #FFFFFF를 사용한다.

## 공통 콘텐츠

shared/content.json이 모든 후보의 문구 원본이다. 회사의 장기 비전과 현재 프로젝트를 혼동하지 않으며 Biadone Edu의 준비 상태를 표시한다. 홈페이지 제목은 ‘하고 싶은 일을, 더 많이 해낼 수 있도록.’, Edu 예시는 ‘반복 업무를, 나만의 자동화로.’다.

## 세 가지 가설

| 방향 | 화면의 중심 | 형태와 여백 | 확인할 점 |
| --- | --- | --- | --- |
| A 정돈된 구조 | 명확한 정보 위계와 직선적인 흐름 | 넓은 흰 바탕, 정렬, 낮은 곡률, 얇은 구분 | 신뢰감과 이해도가 생기는가 |
| B 부드러운 연결 | 편안한 문장과 이어지는 관계 | 밝은 블루 면, 충분한 여백, 큰 곡률, 부드러운 연결 | 친근함 속에서도 유능해 보이는가 |
| C 선명한 강조 | 큰 제목과 선명한 블루 면 | 큰 크기 차이, 단정한 각, 뚜렷한 면의 대비 | 자신감이 느껴지고 정보도 따라오는가 |

같은 레이아웃의 모서리만 바꾸는 비교를 피하고, 글과 도식을 읽는 순서와 면의 구성을 후보별로 다르게 만든다. 장식과 색만 바꾸는 비교는 이번 판단에 충분하지 않다.

```text
A: 제목과 설명을 먼저 읽고, 정렬된 세 흐름을 따라간다.
B: 편안한 제목과 하나로 이어진 도식이 서로 나란히 보인다.
C: 큰 제목과 블루 면의 메시지가 화면을 나누어 차례로 읽힌다.
```

## 제작 방식

사용자가 설치한 design-system, ui-ux-pro-max, frontend-design 스킬을 적용한다. 이미 확정된 SVG·로컬 한국어 폰트·브랜드 조합의 정확한 비교를 위해 HTML/CSS로 편집 가능한 디자인 시안을 만든다. 새 사진이나 일러스트가 필요하지 않은 타이포그래피·도형·레이아웃 비교다. 스타일용 값은 후보 폴더에만 두고 공통 디자인 시스템의 확정값을 바꾸지 않는다.

ui-ux-pro-max 검색에서는 정보 위계, 명확한 행동, 대비·키보드·모바일 검토 원칙을 참고했다. 검색이 제안한 다른 색상·서체와 범용 사이트 구조는 이미 선택된 브랜드 기준에 맞지 않아 채택하지 않았다.

## 검토 방법

나란히 비교한 후 각 홈페이지와 Edu 슬라이드를 크게 볼 수 있는 검토 화면을 만든다. 실제 브라우저에서 문구 일치, 승인 로고, 화면 넘침, 링크, 검토 탭·뷰포트 전환을 확인하고 시각 검토한다. Browser 플러그인이 없어 기존 Playwright를 사용한다. QA 스크립트와 캡처는 임시 폴더에 둔다.
