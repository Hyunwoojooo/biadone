# Biadone 2차 시각 방향 계획

상태: 미승인 탐색안. 기존 1차 세 방향은 사용자가 모두 선택하지 않았다.

현재 사용자 피드백: 2차 세 로고 모두 선호하지 않으며, 세 시안 모두 너무 칙칙하다는 평가를 받았다. 아래 계획과 구현은 비교 기록으로 보존하며, 현재 I 로고를 다음 시안의 전제로 삼지 않는다. 색감과 타이포그래피·구성이 인상에 미친 영향은 추가 확인한다.

## 이번 수정의 기준

색상과 입체 조형을 바꿔도 같은 골격으로 보이던 접근을 바꾼다. 이름의 I를 개인으로 읽고, 같은 형태가 하나 더 생기는 관계를 분신의 시각 언어로 시험한다. 두 번째 I는 같은 기준선과 형태를 공유하면서 한 걸음 앞서 있는 관계다. 무한대, 로봇, 뇌, 일반적인 3D 오브젝트를 사용하지 않는다.

## 세 스킬의 적용

- design-system: 원시값 → 용도 → 컴포넌트의 세 층을 JSON 토큰과 생성 CSS로 연결한다. 후보별 팔레트와 역할은 선택 전 가설이다.
- ui-ux-pro-max: --design-system 검색을 실제 실행하고, 첫 결과의 AI 보라색·브루탈리즘과 재검색의 법률회사 같은 서체는 브랜드와 맞지 않아 채택하지 않았다. 검증된 접근성·반응형 원칙을 적용하고 미학은 이 브리프를 바탕으로 설계한다. 미확인 검색 결과를 MASTER로 저장하지 않는다.
- frontend-design: 같은 색감의 테마 변경을 피하고, A는 이름의 뜻을 쓰는 타이포 포스터, B는 나와 분신의 병렬 리듬, C는 실제 프로젝트를 보여주는 확장 프레임으로 구조부터 구분한다.

## 공통 사실과 문구

- 회사 이름: Biadone.
- 이름의 뜻: Before I ask, Done.
- 홈페이지 메시지 초안: 하고 싶은 일에, 또 하나의 나.
- 비전: 생각과 생활, 작업을 이해하는 나의 분신. Biadone은 그 미래를 향해 제품과 교육을 만듭니다.
- Blabee: AI 에이전트의 다음 선택을 한곳에서 보고, 원래 작업으로 이어갑니다. 로컬 apps/blabee/README.md의 소개를 바탕으로 작성했다.
- Biadone Edu: AI, AX, 자동화를 배우고 적용하는 교육. 준비 중.
- 기본 행동: 만드는 것들 보기. 실제 프로젝트 영역으로 이동한다.
- 없는 고객사, 성과 지표, 후기를 만들지 않는다.

## A 이름이 곧 화면

Barlow Condensed ExtraBold의 Before I ask, Done.을 크게 조판하고 작은 한국어 정보로 의미를 전달한다. 한 화면의 대담함을 큰 문장 하나에 집중한다. 같은 I가 하나 더 나타나는 관계가 로고와 서명으로 이어진다.

팔레트: Ink #172D39, White #FFFFFF, Mist #E8EFF3, Rose #D7435B, Blush #F1D7DC.

## B 나란히 읽는 두 흐름

‘나’와 ‘또 하나의 나’가 같은 기준선에서 생각하고, 만들고, 도전하는 관계를 보여준다. 넓은 두 영역이 대화하듯 나란히 읽히며 한국어 타이포그래피가 주역이다. 비전임을 설명하는 문장을 가까이 둔다.

팔레트: Mineral #385A78, Ink #1D303B, White #FFFFFF, Blue Mist #E4EEF5, Pale Mint #CDE3DE, Sun #F9D673.

## C 프로젝트가 확장되는 프레임

메시지 아래 Blabee와 Biadone Edu가 첫 화면의 큰 면을 차지한다. 카드 두 장 대신 페이지의 바깥 프레임을 두 프로젝트가 공유한다. 노랑과 흰색이 큰 면, 네이비가 글자와 구조를 담당한다.

팔레트: Yellow #FBE275, Navy #263752, White #FFFFFF, Rose #D54B4E, Slate #62718A.

## 서체와 자산

한글 본문과 제목은 로컬 OFL Pretendard Variable을 정확한 굵기와 조판으로 사용한다. 영문 조판에는 로컬 OFL Barlow Condensed ExtraBold를 사용한다. 라이선스를 함께 보존한다. 후보별 글꼴 조합은 아직 최종 승인되지 않았다.

## 구현 범위

concepts/round-02 아래에 정적 HTML/CSS/JavaScript의 비교 페이지와 독립된 세 홈페이지 시안을 만든다. 비교 페이지 밖의 운영 사이트는 수정하지 않는다. npm 의존성을 추가하지 않는다. 실제 UI 텍스트와 조작 요소는 코드로 만든다. 각 후보에서 강의자료와 SNS로 확장하는 시각 표본도 비교할 수 있게 한다.

## 검토 기준

- A/B/C를 색 없이 봐도 화면 구조로 구분할 수 있는가.
- Biadone의 이름과 개인의 분신이라는 목표가 시각적으로 연결되는가.
- 유능함과 신뢰를 유지하면서 과하게 딱딱하지 않은가.
- 한글 제목, 실제 본문, 프로젝트 이름이 모두 읽히는가.
- 데스크톱과 작은 휴대폰에서 가로 넘침이나 잘림이 없는가.
- 주요 텍스트와 버튼 대비, 키보드 포커스, 앵커 이동, 비교 탭, 줄임 모션 설정을 확인한다.

## 사전 자체 비평

A의 큰 영문 문장만 남으면 비전이 영어 포스터처럼 보일 수 있어 한국어 메시지와 프로젝트를 첫 화면에 둔다. B의 두 영역은 현재 제공되는 자동 실행 제품으로 오해하지 않게 장기 비전을 함께 명시한다. C는 교육회사로만 읽히지 않도록 회사의 장기 목표를 먼저 보여준다. 세 방향의 영문/한글 비율과 콘텐츠 위치를 다르게 설계해 같은 골격의 색상 변경을 피한다.

## 열어보기와 수정

index.html을 열면 세 방향, 데스크톱과 휴대폰 미리보기, 강의 표지와 SNS 적용 예시를 비교할 수 있다. 별도의 npm 설치나 빌드는 필요하지 않다.

로컬 서버로 볼 경우 다음 명령을 쓴다.

```sh
python3 -m http.server 4325 --bind 127.0.0.1 --directory /Users/joo/BiaDone/brand/concepts/round-02
```

후보별 tokens.json이 색상과 컴포넌트 토큰의 원본이다. 설치된 design-system의 generate-tokens.cjs로 해당 후보의 tokens.css를 생성한다. 후보 토큰을 수정한 뒤에는 아래 명령으로 비교 페이지의 매체별 예시 색상도 갱신한다.

```sh
node /Users/joo/BiaDone/brand/concepts/round-02/shared/generate-specimens.mjs
```

## 렌더를 보며 조정한 점

- 비교 페이지가 첫 시안을 불필요하게 두 번 로드하던 부분을 정리했다.
- C에서 프레임과 중복되던 하단 작은 짝 표식을 제거했다.
- B는 첫 화면 아래로 프로젝트가 이어지므로 스크롤 가능한 웹 원본과 휴대폰 미리보기를 함께 제공한다.
- 세 홈페이지의 375, 768, 1024, 1440, 1536px 가로 크기에서 넘침을 확인했다. 시안 전환과 화면 크기 전환, 본문 건너뛰기 포커스, 프로젝트·비전 앵커도 검토했다.
- 연결된 Browser 플러그인이 없고 CUA의 iab와 브라우저 목록도 이용할 수 없어, 설치된 Playwright Chromium으로 렌더했다.
