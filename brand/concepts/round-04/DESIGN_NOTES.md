# Biadone 심벌 탐색

상태: 2026-10-27 사용자가 **B 맞물린 두 면, 간격 약 2.83의 2차 수정안**을 확정했다. 공통 기준 원본은 ../../design-system/assets/logo/에 정리했다.

## 고정한 조건

- 대표 블루: #2858F0.
- 워드마크: Pretendard 600으로 같은 크기와 간격을 사용한다.
- 밝은 바탕, 블루 위의 흰색, 단색을 같은 조건으로 비교한다.
- 기존 I 심벌은 사용하지 않는다.
- 로고의 그림자, 입체 효과, 다른 색상과 서체로 형태의 차이를 가리지 않는다.

## 후보

### A 이름을 닮은 B

Biadone의 B를 두 둥근 볼과 정렬된 내부 공간으로 그렸다. 윗볼에는 열린 틈을 두고 아래 볼은 조금 더 넓혀 단단한 기반을 만든다. 이름을 떠올리게 하는 모노그램 후보다.

### B 맞물린 두 면

사선으로 마주 보는 같은 면 두 개를 180도 회전해 배치했다. 두 모양 사이에 열린 통로를 남겨, 두 존재가 함께 공간을 만드는 관계를 시험한다.

### C 부드러운 아치

높고 단단한 B, 사선의 두 면과 다른 곡선 실루엣이다. 생각에서 실행으로 이어지는 통로를 표현하는 후보이며, 큰 열린 여백과 비대칭 끝부분, 앞으로 향하는 기울기를 사용한다.

위 설명은 후보를 제작할 때의 탐색 의도다. 최종 선택은 B의 2차 수정안이다.

## 소스와 재생성

- symbols.json: 후보의 이름, 설명, 64 × 64 좌표의 SVG 도형.
- generate-symbols.mjs: 공통 디자인 시스템의 현재 색상으로 SVG 세 가지 버전을 생성한다.
- assets/symbol-a.svg 등: 블루 원본.
- assets/symbol-a-white.svg 등: 블루 바탕에 올릴 흰색 원본.
- assets/symbol-a-ink.svg 등: 단색 원본.
- brand.tokens.css: ../../design-system/tokens.json에서 생성한 비교 페이지용 토큰.
- layout.tokens.css: 비교 화면의 크기와 간격이며, 최종 브랜드 레이아웃 규칙은 아니다.

```sh
node /Users/joo/BiaDone/brand/concepts/round-04/generate-symbols.mjs
node /Users/joo/.agents/skills/design-system/scripts/generate-tokens.cjs --config /Users/joo/BiaDone/brand/design-system/tokens.json -o /Users/joo/BiaDone/brand/concepts/round-04/brand.tokens.css
```

SVG는 래스터 이미지를 자동 추적한 결과가 아니라 편집 가능한 도형이다. 워드마크는 실제 Pretendard로 렌더한다. 비교 페이지의 글꼴은 앞선 비교 자료의 동일한 로컬 WOFF2를 참조하며, 공통 기초의 원본과 동일하다.

## 확인할 항목

- 심벌의 실루엣과 이름을 함께 보았을 때의 인상.
- 심벌만 썼을 때의 식별 가능성.
- 16, 24, 32, 48 CSS px에서의 여백과 획.
- 블루와 흰색 반전, 단색 사용에서 형태 유지.
- 선택 후 조정할 곡선, 획 두께, 이름과의 비율.

## 선택 상태

2026-10-27 사용자는 B가 좋으며 두 도형 사이의 간격은 더 좁히되 정사각형을 유지하기를 원한다고 설명했다. B를 선택 방향으로 기록한다. 색감과 Pretendard는 유지한다.

추가 비교 후 사용자는 간격 약 2.83을 확정했다. 심벌의 형태와 내부 간격은 이 버전을 기준으로 사용한다. 이름과의 조합 비율 및 매체별 사용 규격은 이어서 정한다.

## B 간격 수정

두 도형을 통째로 이동하지 않고 외곽 모서리는 고정한 채 안쪽 사선만 중앙 쪽으로 넓혔다. 두 번째 도형은 여전히 첫 도형을 중심 (32,32)에 대해 180도 회전한 형태다.

| 항목 | 최초 | 1차 수정 | 최신 2차 수정 |
| --- | --- | --- | --- |
| SVG 캔버스 | 64 × 64 | 64 × 64 | 64 × 64 |
| 심벌 외곽 범위 | x8–56, y8–56 | x8–56, y8–56 | x8–56, y8–56 |
| 심벌 바깥 크기 | 48 × 48 | 48 × 48 | 48 × 48 |
| 사선 사이의 수직 거리 | 약 9.90 | 약 5.66 | 약 2.83 |

단위는 SVG 내부 좌표다. 1차에서 간격을 약 43% 좁혔고, 사용자의 추가 요청으로 2차에서 그 간격을 다시 절반으로 줄였다. 최초 대비 약 71% 좁아진 형태다. 위 값은 사용자 요청을 반영한 제작값이며, 전체 사용 규격을 최종 확정한 것은 아니다.

- b-refinement.html: 직전 1차와 최신 2차 수정안을 같은 크기로 비교하는 화면.
- assets/symbol-b-before.svg 등: 최초 버전 보존본.
- assets/symbol-b-r1.svg 등: 1차 수정안 보존본.
- assets/symbol-b.svg 등: 간격을 좁힌 최신 수정안.

브라우저의 실제 SVG 경계와 도형 내부 판정으로 측정했다. 직전과 최신 수정안의 외곽은 모두 48 × 48이며, 간격은 약 5.65685에서 2.82842로 줄었다. 16–48px 크기, 반전·단색 표시와 375–1536px 화면을 확인했고 가로 넘침이나 브라우저 오류는 없었다. 작은 크기와 모바일 비교 화면도 시각 검토했다.

B만 재생성할 때는 아래 명령을 사용할 수 있다. 생성기는 같은 내용의 파일을 다시 쓰지 않으며, 이번 수정에서 A·C 심벌은 유지했다.

```sh
node /Users/joo/BiaDone/brand/concepts/round-04/generate-symbols.mjs b
```

## 현재 대비 70% 추가 축소 비교안

사용자가 현재 상태에서 간격을 70% 줄인 버전도 보고 싶다고 요청했다. 현재 간격 2√2(약 2.82843)를 기준으로 30%만 남겨, 새 간격은 0.6√2(약 0.84853)다. 최초 대비 70%가 아니라 현재 2차 수정안 대비 70% 추가 축소다.

- b-gap70.html: 현재와 70% 추가 축소안을 비교하는 별도 화면.
- assets/symbol-b-r2.svg 등: 현재 2차 수정안의 고정 보존본.
- assets/symbol-b-gap70.svg 등: 70% 추가 축소 비교안. 기본 symbol-b.svg는 유지한다.
- 정사각형 외곽은 동일하게 x8–56, y8–56의 48 × 48이다.
- 새 사선은 x+y=63.4와 x+y=64.6이며, 두 도형은 여전히 서로 180도 회전한 같은 형태다.

이 버전은 비교 기록으로 보존한다. 사용자가 확정한 간격은 2.83이다.

브라우저에서 측정한 간격은 현재 약 2.82842, 추가 축소안 약 0.84852로 감소율 약 70%를 확인했다. 외곽은 두 버전 모두 x8, y8, 48 × 48이다. 16–48px와 375–1536px 화면, 블루·흰색·단색 표시를 확인했고 가로 넘침이나 브라우저 오류는 없었다. 작은 크기에서는 사선이 매우 가늘게 보인다. 기존 SVG와 공통 도형 원본은 변경하지 않았다.
