# Biadone 브랜드 브리프

상태: 인터뷰 진행 중 · v0.1

Biadone 전체가 공유할 디자인 시스템의 출발점이다. 사용자에게 확인한 내용과 검토 중인 표현을 구분해 기록한다.

## 이름과 출발점

**Biadone = Before I ask, Done.**

창업자 자신에게 정말 잘 맞는, 자신의 분신 같은 비서이자 워커를 만들고 싶다는 생각에서 출발했다.

그 존재는 자신의 생각을 온전히 이해하고, 생활과 작업을 이해해야 한다. 이해하는 역할과 실제 일을 수행하는 역할을 함께 갖는 것이 목표다.

## 장기 비전

자신의 분신을 데이터화하고 구현한다. 현재의 서브프로젝트들을 진행하고 시드머니를 마련하면서 이 목표를 향해 나아간다.

이 비전은 장기 목표이며, 현재 서비스가 이미 제공하는 기능을 뜻하지 않는다.

## 현재의 회사와 서비스 구성

| 이름 | 사용자에게 확인한 역할과 상태 |
| --- | --- |
| Biadone | 여러 서비스를 운영하며 장기 비전을 추구하는 회사 |
| Blabee | 이 목표를 향해 가는 과정에서 처음 만든 서브프로젝트 |
| Biadone Edu | AI, AX, 자동화 관련 교육을 제공하기 위해 준비 중인 사업 |

서브프로젝트들을 통해 시드머니를 마련하는 계획은 내부 사업 맥락으로 기록한다. 대외 브랜드 메시지는 별도로 정한다.

## 우선 도울 사람

창업자 자신처럼 여러 일을 하고, 다양한 일을 직접 구현해보는 것을 좋아하는 사람들이다. 몸은 하나지만 다양한 일을 해보고 싶고, 여러 도전을 이어가고 싶어 한다.

사용자는 대상을 직업명보다 다음과 같은 성향과 상황으로 설명했다.

- 관심사가 다양하고 여러 일을 해보고 싶다.
- 아이디어를 실제로 구현하는 것을 좋아한다.
- 혼자서 할 수 있는 일의 한계 속에서도 다양한 도전을 하고 싶다.

구체적인 직업군, 기술 숙련도, 대표적인 사용 상황은 아직 정하지 않았다.

## 브랜드 성격과 원하는 인상

중심 인상은 **유능함과 든든함**이다. 사람들이 믿고 일을 맡길 수 있도록 신뢰를 주는 것이 중요하다.

태도에는 **유연함**이 있어야 한다. 지나치게 딱딱한 느낌은 피하고, 상황에 맞게 융통성 있게 대하는 인상을 원한다.

사용자 답변을 정리한 표현 초안:

> 믿고 맡길 수 있고, 편안하게 함께 일할 수 있는 존재.

색상, 서체, 로고와 같은 시각적 표현은 이 성격을 바탕으로 별도 검토한다.

## 시각 자산의 출발점

사용자는 이번에 Biadone의 시각적 정체성을 새로 만든다고 설명했다. 유지해야 할 기존 로고, 색상, 서체는 없으며 모두 새로 설계한다.

이전에 제작된 홈페이지나 자료의 표현은 이번 시스템의 확정된 기준으로 취급하지 않는다.

## 적용 우선순위

사용자가 정한 순서에 따라 확장한다.

1. 회사 소개 홈페이지.
2. Biadone Edu 강의자료와 소개서.
3. 유튜브와 SNS 콘텐츠.
4. 서비스 화면 또는 앱 UI.

첫 시각 방향은 회사 소개 홈페이지의 첫 화면을 같은 콘텐츠로 비교하며 검토한다.

## 시각 방향 검토 현황

[1차 이미지 시안](concepts/round-01/CONCEPTS.md)은 사용자가 세 방향 모두 애매하고 평범하다고 평가했으며 선택하지 않았다. 자료는 비교 기록으로 보존한다.

사용자가 지정한 design-system, ui-ux-pro-max, frontend-design 스킬을 적용해 [2차 웹 시안](concepts/round-02/index.html)과 [설계 계획](concepts/round-02/DESIGN_PLAN.md)을 만들었다.

2차에서는 이름 속 I를 개인으로 읽고, 같은 형태가 하나 더 나타나는 관계로 분신을 표현하는 ‘두 번째 I’를 시험했다. 세 방향은 색상뿐 아니라 화면의 구조와 타이포그래피도 다르게 설계했다.

- A 이름이 곧 화면: Before I ask, Done.의 큰 영문 조판을 중심으로 이름의 의미를 시각 자산으로 쓴다.
- B 나란히 읽는 두 흐름: 나와 분신을 같은 리듬의 한국어 조판과 병렬 구조로 보여준다.
- C 확장되는 프레임: 실제 프로젝트가 큰 면을 차지하고 공통 프레임으로 연결된다.

2차 피드백에서 사용자는 세 로고 모두 선호하지 않으며, 세 시안 모두 너무 칙칙하다고 평가했다. 현재의 I 로고 형태는 다음 시안의 전제로 유지하지 않는다.

사용자는 칙칙한 인상의 주된 원인이 색감이라고 설명했다. Pretendard의 가독성은 좋게 평가하지만 딱딱한 느낌도 있다고 말했다. Pretendard를 전면 배제한 것은 아니며, 더 부드러운 인상의 서체 후보와 실제 문구를 비교한다.

다음 비교에서는 같은 레이아웃과 서체로 밝은 팔레트를 먼저 비교하고, 같은 색과 문구로 서체를 비교해 판단할 요소를 분리한다. 개별 레이아웃에 대한 선호는 아직 정하지 않았다. 후보별 세 층 토큰 구조는 유지하되, 후보 값과 그래픽은 피드백에 맞춰 다시 설계한다.

[3차 색감·서체 비교](concepts/round-03/index.html)에서 사용자가 **A 맑은 블루와 Pretendard**를 선택했다. 대표 색상은 #2858F0, 밝은 블루 바탕은 #EEF5FF, 기본 글자는 #23314D, 기본 바탕과 블루 위의 글자는 #FFFFFF다.

선택한 색감과 서체는 [공통 기초 v0.1](design-system/FOUNDATIONS.md)과 세 층의 tokens.json, 생성 CSS, 로컬 글꼴로 분리했다. 홈페이지 레이아웃, 세부 조판, 여백과 컴포넌트 규격은 이어서 결정한다.

사용자는 로고에 심벌이 있기를 원한다고 설명했다. 심벌과 Biadone 이름을 함께 쓰는 형태로 진행한다. [4차 심벌 비교](concepts/round-04/index.html)에서 **B 맞물린 두 면**을 선택했고, 두 도형 사이의 간격을 좁히면서 정사각형 외곽은 유지하기를 원했다. [B 간격 수정안](concepts/round-04/b-refinement.html)은 바깥 크기를 유지하고 안쪽 사선의 틈을 좁힌 버전이다.

추가 비교를 마친 뒤 **간격 약 2.83의 B 심벌을 확정**했다. [공통 심벌 원본](design-system/assets/logo/biadone-symbol.svg)과 흰색·단색 변형을 design-system/assets/logo/에 정리했다.

[5차 심벌·이름 조합 비교](concepts/round-05/index.html)에서 같은 심벌과 서체로 A 이름 중심, B 균형형, C 심벌 중심의 크기·간격을 제안했고, 사용자가 **B 균형형**을 확정했다. 이름은 Pretendard 600, 자간 -0.04em이며 심벌 높이는 글자 크기의 11/12, 이름과의 거리는 1/3이다.

[6차 전체 화면 스타일 비교](concepts/round-06/index.html)에서 같은 문구와 공통 브랜드 자산으로 세 방향을 제안했고, 사용자가 **A 정돈된 구조**를 선택했다. 넓은 흰 바탕, 명확한 정렬과 위계, 작은 곡률, 얇은 구분선과 직선적인 흐름을 [공통 화면 기준](design-system/SCREEN_STYLE.md)에 반영했다. 이 단계의 문구와 교육 예시는 시각 검토용이다.

[7차 그래픽 표현 비교](concepts/round-07/index.html)에서 A 라인형, B 면 강조형, C 주석형을 제안했으나 사용자는 세 세트 모두 선호하지 않았다. 파란 세로선·색상 면·괄호 프레임 같은 일반적인 강조 템플릿에서 벗어난 브랜드 고유의 표현이 필요하다. 사용자는 세 세트 모두 흔한 템플릿처럼 보인다는 이유를 확인했다. 기존에 확정한 A 전체 화면 스타일은 유지한다.

[8차 맞물린 작업면 연구](concepts/round-08/index.html)에서 심벌 안에 요청문과 초안을 담았으나, 사용자는 담을 수 있는 내용이 제한적이라는 한계를 지적했다. 공통 정보 화면의 기본 틀로 사용하지 않는다. [9차 가변 구조 검증](concepts/round-09/index.html)을 본 뒤, 사용자는 **내용은 유연하게 담고 브랜드 특징은 여백과 경계에서 드러내는 방향**을 좋게 평가했다. 공통 원칙으로 확정하고 세부 모티프와 매체별 규격을 이 기준으로 정리한다.

## 추가 서체 검토

사용자는 기본 제작 키트를 본 뒤 Pretendard 외의 서체도 검토하고 싶다고 설명했다. [10차 서체 검토](concepts/round-10/index.html)에서 Pretendard를 기준으로 Wanted Sans·나눔스퀘어 네오·LINE Seed KR의 글자 표본과 실제 홈페이지·Edu를 비교했다. 이 단계에서는 새 후보를 확정하지 않았다.

사용자는 이 고딕 후보들이 비슷하게 보인다고 평가했고, 형태가 다른 서체 다섯 가지를 요청했다. [11차 제목 서체 비교](concepts/round-11/index.html)에서 SUITE·Gmarket Sans·마루 부리·고운돋움·도현을 같은 문구로 비교한 뒤 **A · SUITE를 선택**했다. 공통 제목·소제목·핵심 문장·흐름과 단계 제목은 SUITE 700, 본문·표·조작 요소와 로고 이름은 Pretendard로 정리했다. 로고 이름은 기존 600을 유지한다.

## 브랜드 방향 표현 초안

> 나를 깊이 이해하고, 내 생각을 실행과 완료로 연결하는 나의 분신.

위 문장은 사용자 설명을 바탕으로 정리한 검토용 표현이다. 공식 슬로건은 추후 결정한다.

## 다음에 결정할 내용

1. [기본 제작 키트 v0.1](design-system/index.html)의 홈페이지·Edu HTML/CSS 기본형을 실제 원고에 적용한다. 반복 요소와 가변 정보 구조의 세부 규격을 다듬는다.
2. 실제 사용 환경을 바탕으로 보호 여백, 최소 크기, 세부 조판과 제작 규칙 정리.
3. 우선 대상이 도움받고 싶은 구체적인 일상 또는 작업 상황.
4. 회사 전체가 공유할 브랜드 기준과 서비스별 표현의 범위.

## 진행 기록

- 2026-10-26: 사용자가 설명한 이름의 의미, 창업 동기, 장기 비전, Blabee와 Biadone Edu의 위치를 기록했다.
- 2026-10-26: 우선 대상을 다양한 일의 구현과 도전을 좋아하는 사람들로 기록했다.
- 2026-10-26: 브랜드의 중심 인상은 유능함과 든든함이며, 신뢰와 유연한 태도를 원한다는 답변을 반영했다.
- 2026-10-26: 유지해야 할 기존 시각 자산 없이 로고, 색상, 서체를 새로 설계하기로 했다.
- 2026-10-26: 적용 순서를 회사 소개 홈페이지, Biadone Edu 자료, 유튜브와 SNS, 서비스 화면과 앱 UI로 정했다.
- 2026-10-26: 회사 소개 홈페이지 첫 화면을 기준으로 세 방향의 비교용 이미지를 제작했다. 선택과 최종 확정은 사용자 검토 후 진행한다.
- 2026-10-26: 사용자가 1차 세 방향을 모두 선택하지 않았고, design-system, ui-ux-pro-max, frontend-design 스킬을 적용해 다시 제작하도록 요청했다.
- 2026-10-26: 같은 골격의 색상 변경을 피하고 타이포 포스터, 병렬 흐름, 확장 프레임의 세 웹 시안을 제작했다. 모두 검토용이며 운영 사이트에는 적용하지 않았다.
- 2026-10-26: 사용자는 2차의 세 로고 모두 선호하지 않으며, 세 시안 모두 너무 칙칙하다고 평가했다. 로고와 화면의 인상을 재검토한다.
- 2026-10-26: 칙칙함의 주된 원인은 색감이며 Pretendard는 읽기 좋지만 딱딱하게 느껴진다는 답변을 반영했다. 팔레트와 서체를 분리해 비교한다.
- 2026-10-26: 로고를 제외한 색감·서체 비교 보드를 만들었다. 밝은 세 팔레트와 실제 한글 서체 세 가지를 같은 조건에서 비교한다.
- 2026-10-26: 사용자가 3차 A 맑은 블루와 Pretendard를 선택했다. 선택된 기초를 design-system에 별도로 정리하고 비교 페이지의 기본 조합도 동일하게 맞췄다.
- 2026-10-26: 사용자가 심벌이 있는 로고를 원한다고 설명했다. 선택된 색감과 서체로 심벌+이름, 단독 심벌, 작은 크기와 단색을 비교하는 자료를 만들었다.
- 2026-10-27: 사용자가 B 맞물린 두 면을 선택했고, 사이 간격을 좁히되 정사각형 외곽을 유지하도록 요청했다. 외곽 48 × 48을 유지하고 사선 간격을 약 43% 좁힌 수정안과 이전 버전의 비교 화면을 제작했다.
