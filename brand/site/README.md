# Biadone 공유용 브랜드 가이드

확정된 공통 디자인 기준과 홈페이지·Edu HTML/CSS 템플릿을 정적 사이트로 묶습니다. 원본은 `design-system/`, 공개 출력은 이 폴더의 `public/`입니다.

```sh
node site/build.mjs
python3 -m http.server 4328 --directory site/public
```

공유용 출력만 배포합니다. `build.mjs`와 이 안내, 배포 기록은 공개 출력에 포함하지 않습니다. 배포 대상과 실행은 배포 담당자의 안내를 따릅니다.

빌드에는 Node.js 내장 모듈과 Python 3 표준 ZIP 라이브러리만 사용합니다. 새 패키지를 설치하지 않습니다. `site/_headers`를 공개 출력에 그대로 복사하므로 배포 헤더 원본이 먼저 준비되어 있어야 합니다.

허용 목록의 공통 CSS·토큰·심벌·웹폰트와 라이선스·템플릿만 복사합니다. 내부 브리프·과거 시안·작업 지침·환경 파일·캐시를 포함하지 않습니다. 기존 출력에서 예상 밖 파일을 발견하면 지우지 않고 빌드를 중단합니다.

공개 가이드는 공통 기초, 화면 스타일, 반복 요소, 템플릿 편집 안내를 HTML로 제공합니다. `downloads/biadone-brand-kit-v0.1.zip`에는 같은 기본 원본과 공개 사용 안내가 포함됩니다. ZIP의 웹 가이드는 로컬 서버에서 열 수 있으며, PPTX·Figma 편집 파일이나 데스크톱용 폰트가 있는 것처럼 안내하지 않습니다.

공개 출력의 `manifest.json`은 배포 파일의 SHA-256을 기록합니다. ZIP은 정렬된 파일 목록과 고정된 메타데이터를 사용해 같은 입력에서 같은 결과가 나오도록 생성합니다. 배포 전 링크·폰트·Edu 재분할·다운로드·404와 공개 파일 목록을 확인합니다.
