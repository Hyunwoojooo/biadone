# Biadone 공통 화면 스타일

상태: 2026-10-27 사용자 선택. 6차의 **A 정돈된 구조**와 9차의 **가변 정보 영역·브랜드 표현의 역할 분리** 방향을 공통 기준으로 사용한다.

## 화면을 만드는 기준

1. 넓은 흰 바탕에 제목·설명·행동·보조 정보를 정렬한다. 제목은 크게, 본문은 편안하게 읽히는 위계를 만든다.
2. 블루는 주요 행동, 단계의 시작점과 핵심 연결에 사용한다. 기본 글자는 ink다.
3. 관련 정보는 정렬과 여백, 얇은 구분선으로 묶는다. 내용의 구분이 필요한 곳에 면을 사용한다.
4. 과정은 직선과 작은 정사각형 시작점을 사용해 순서대로 보여준다. 넓은 화면에서는 가로, 좁은 화면에서는 세로로 이어간다.
5. 모서리의 곡률은 작게 유지하고, 전체 정보량에 따라 여백을 조정한다.
6. 홈페이지와 강의자료는 색상·서체·로고·정렬·흐름 표현을 공유하며, 글자 크기와 정보량은 매체에 맞춘다.
7. 본문·표·과정의 영역은 내용량에 따라 늘어나야 한다. 심벌의 윤곽에 맞춰 정보를 줄이거나 글자를 축소하지 않는다. 브랜드 조형이 정보 영역을 자르지 않도록 구성한다.
8. 웹 문서는 내용에 맞춰 세로로 확장한다. 슬라이드처럼 크기가 고정된 매체는 가독성을 유지하며 내용을 여러 장으로 나눈다.

## 확정된 정보 영역과 브랜드 표현의 역할

사용자는 9차 검증의 방향을 좋게 평가했다. 본문·표·과정은 내용의 양과 구조에 따라 배치하고, 브랜드의 사선 접합은 여백·경계·머리말처럼 내용과 분리된 위치에서 사용한다.

- 정보가 늘어나면 영역과 페이지 구성이 대응한다. 내용을 심벌 안에 억지로 맞추지 않는다.
- 모티프를 표시하거나 생략해도 정보의 위치·순서·가독성이 유지되어야 한다.
- 머리말의 접합 표시는 초기 적용 예시다. 크기·간격·위치는 매체와 내용에 맞춰 정리한다.
- 고정 슬라이드의 분할은 [Edu HTML/CSS 템플릿](templates/edu/index.html)에 구현했다. 1600×900에서 본문·표·단계를 실제 높이로 측정하며, 글자 크기를 줄이지 않고 여러 장으로 나눈다.

## 선택한 예시에서 가져온 기초값

| 용도 | 시작값 |
| --- | --- |
| 기본 모서리 | 4px |
| 연결선 | 1px |
| 단계의 정사각형 시작점 | 12px |
| 같은 묶음의 간격 | 24px |
| 웹의 단계 열 간격 | 32px |
| 웹의 큰 구획 여백 | 96px |
| 웹 바깥 여백 | 데스크톱 48px, 모바일 24px |
| 웹 내용 최대 너비 | 1280px |
| Edu 예시 캔버스 | 1600×900 |
| Edu 좌우 여백 / 단계 열 간격 | 72px / 48px |

이 값은 선택한 홈페이지·Edu 예시의 재사용 출발점이다. 내용과 매체가 달라질 때 같은 정보 위계가 유지되도록 조정한다. 세부 컴포넌트의 모든 규격을 한 번에 확정한 것은 아니다.

## 조판 기준 예시

11차에서 선택한 **SUITE 700을 제목**, **Pretendard를 본문·정보·조작 요소**에 사용한다. 웹 제목의 줄 간격은 1.19이며 화면 너비에 따라 크기가 변한다. 웹 본문은 데스크톱 18px, 모바일 16px가 출발점이다.

6차의 단일 Edu 예시는 당시 Pretendard 제목 80px·650, 단계 제목 32px·600, 단계 본문 23px의 비교 기록이다. 현재 여러 장 구성의 기본 키트는 SUITE 제목 64px·700, SUITE 단계 제목 32px·700, Pretendard 본문 26px·표와 단계 본문 24px를 사용한다. 내용량에 따라 글자를 축소하지 않는다. 로고의 이름 조판은 이미 확정한 Pretendard 600·B 균형형을 유지한다.
