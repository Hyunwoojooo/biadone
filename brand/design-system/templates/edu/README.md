# Edu HTML 소스 템플릿

이 폴더는 디자인 시스템에 포함되는 **편집 가능한 HTML/CSS 소스 템플릿**입니다. PPTX, 배포된 강의, 신청 페이지 또는 완성된 교육 상품이 아닙니다. 미리보기의 교육 문구는 `concepts/round-09/content.json`에서 가져온 예시이며, 표지와 요약 문구는 해당 내용을 바탕으로 작성했습니다.

## 파일과 실행

- `index.html`: 슬라이드의 공통 HTML 구조와 바깥 보기 도구. `<template id="slide-template">`에서 로고·머리말·제목·출처·쪽수 구조를 편집합니다.
- `layout.css`: 1600×900 캔버스와 유형별 배치, 보기 도구의 CSS. 브랜드 색·서체·슬라이드 글자 크기는 `../../biadone.css`를 따릅니다.
- `edu.tokens.json` → `edu.tokens.css`: 공통 토큰에 없는 페이지 선택 너비·보기 도구 간격 등의 원시값 → 의미 → 컴포넌트 토큰. 생성 CSS를 직접 수정하지 않습니다.
- `content.json`: 표지, 본문 6개 문단, 4열 비교표 7행, 6개 순서, 요약과 출처의 샘플 원문.
- `renderer.js`: 실제 글꼴과 가용 높이를 측정하는 페이지 분할 및 탐색 기능.

저장소 루트에서 기존 정적 서버를 사용하거나 다음과 같이 실행한 뒤 `/design-system/templates/edu/`를 엽니다. JSON을 불러오므로 `file://`로 직접 열기보다 HTTP 서버를 사용합니다.

```sh
python3 -m http.server 8080
```

`content.json`의 문구를 편집한 뒤 새로고침하면 페이지가 다시 나뉩니다. 원문의 배열 순서는 유지됩니다. 샘플을 실제 내용으로 교체할 때 `meta.sampleLabel`, `meta.source`, 요약의 출처도 함께 검토합니다.

로컬 토큰 CSS는 저장소 루트에서 다음과 같이 다시 생성합니다.

```sh
node /Users/joo/.agents/skills/design-system/scripts/generate-tokens.cjs --config design-system/templates/edu/edu.tokens.json -o design-system/templates/edu/edu.tokens.css
```

## 레이아웃과 분할 규칙

캔버스는 항상 1600×900입니다. 제목 64px, 본문 26px, 표 24px, 단계 제목 32px·본문 24px은 공통 CSS에서 가져오며, 내용이 많아져도 줄이지 않습니다. 보기 도구의 배율은 캔버스 전체에만 적용합니다. 페이지 수는 항목 수를 고정 계산한 값이 아니라 로드된 글꼴, 제목 줄 수, 표 행 높이와 단계 배치를 실제로 측정한 결과입니다.

측정 전에 슬라이드 원본의 임시 복제본에서 제목과 본문의 실제 `font-family`·굵기·크기를 읽습니다. 각 첫 번째 서체를 단독으로 불러와 성공을 확인한 뒤 페이지를 나눕니다. 기본 조합은 SUITE 제목과 Pretendard 본문이며, 비교 화면에서 제목을 다른 서체로 바꾼 경우에도 실제 적용된 서체를 기다립니다. 파일 로드에 실패하면 대체 서체로 측정하고 화면 상태에 실패한 역할과 서체 이름을 표시합니다.

본문은 문단 단위로 옮기고, 문단 하나가 빈 페이지에도 들어가지 않을 때 문장 경계에서 나눕니다. 표는 행 단위로 나누고 매 페이지에 제목과 열 머리말을 반복합니다. 단계는 각 항목을 유지하면서 가용 높이에 따라 나누며, 다음 장에서도 전체 순서 번호를 이어갑니다. 요약도 문단과 출처 묶음의 높이를 측정합니다. 모든 페이지에는 예시 표시, 출처와 전체 기준 쪽수가 있습니다.

문장 하나·표의 행 하나·단계 하나 또는 제목처럼 더 나누기 어려운 항목이 한 페이지보다 크면 원문을 유지하고 슬라이드에 **편집 필요** 메시지를 표시합니다. 해당 페이지는 캔버스 밖으로 나온 내용도 보기 영역에서 확인할 수 있도록 확장됩니다. 이 상태는 완성된 페이지로 간주하지 말고 원문이나 항목 구조를 편집해야 합니다.

## 보기 도구

이전·다음 버튼, 페이지 선택, ←·→·Home·End 키를 사용할 수 있습니다. 입력·선택 컨트롤 안의 키 조작은 해당 컨트롤에 맡깁니다. `화면에 맞춤`은 보기 영역에 맞춰 표시하고 `원본 크기`는 1600×900 크기를 유지합니다. `전체 보기`는 모든 페이지를 이어 보여줍니다. 보기 도구와 배율 정보는 슬라이드 표면 밖에 있습니다. 자동 인쇄 또는 내보내기는 실행하지 않습니다.

## 검증 범위

브라우저 검토 시 로컬 SUITE·Pretendard 로드, 각 페이지의 여백과 줄바꿈, 본문 6개·표 행 7개·단계 6개의 보존, 이어지는 표 머리말, 전체 단계 번호와 쪽수, 키보드 조작을 확인해야 합니다. 원문이 길어질 때의 문장 분할과 편집 필요 표시도 별도로 확인합니다. 브라우저가 바뀌거나 공통 CSS·콘텐츠를 수정하면 다시 확인합니다.

`window.biadoneEdu.getSnapshot()`은 페이지 수·유형별 쪽수·원문/렌더 항목 수·넘침 페이지·문단 복원 결과를 반환합니다. 기존 `fontLoaded`는 제목·본문의 첫 선택 서체가 모두 로드됐는지 나타내는 boolean이며, `fontReadiness.heading`과 `fontReadiness.body`에는 실제 서체 이름·굵기·크기·로드 결과가 들어 있습니다. `window.biadoneEdu.render(data)`는 파일을 바꾸지 않고 수정한 JSON 객체로 다시 렌더링할 수 있는 검토용 진입점입니다.

이 소스의 검증은 HTML 화면에 한정됩니다. PowerPoint/Keynote 변환, PDF 인쇄, 동영상, 학습 효과, 실제 강의 운영이나 사람의 최종 편집 승인을 보증하지 않습니다.
